Lectures 6–7

Induction, well-ordering and recursion

Lectures 6 and 7 are about one idea in four forms: regular induction, strong induction, the well-ordering property and structural induction. All four are equivalent ways of saying that the positive integers can be reached from 1 by adding 1 again and again. Induction proves a statement once you have guessed it; it does not find the statement for you.

4.1Regular induction

Principle I (RI)

To prove that P(n) is true for every positive integer n:

Basis step. Show that P(1) is true.
Inductive step. Show that P(k) → P(k + 1) is true for every positive integer k: assume P(k) (the inductive hypothesis) and deduce P(k + 1).

In the language of Lectures 2–3: [P(1) ∧ ∀k (P(k) → P(k + 1))] → ∀n P(n).

To prove P(n) for n ≥ b, start the basis at P(b) and do the inductive step for every k ≥ b. The integer b may be 0 or negative.

Template for a proof by regular induction

  1. Write the claim as “for all n ≥ b, P(n)” and say what P(n) is.
  2. Basis step. Show that P(b) is true, with the right value of b.
  3. Inductive step. State the hypothesis: “assume P(k) is true for an arbitrary fixed integer k ≥ b”. Write out what P(k + 1) says. Prove it, and point to the place where you use P(k).
  4. Conclusion. “By mathematical induction, P(n) is true for all integers n ≥ b.”

The proof never assumes that P(k) is true for all k. It shows only that if P(k) is true, then P(k + 1) is true.

Example 1

Claim: 1 + 2 + ⋯ + n = n(n + 1)/2. Basis: 1 = 1·2/2. Inductive step: assume 1 + ⋯ + k = k(k + 1)/2. Add k + 1 to both sides:

1 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k(k + 1) + 2(k + 1))/2 = (k + 1)(k + 2)/2,

which is P(k + 1). ∎

Example 2: guess, then prove

The sums of the first odd numbers are 1, 4, 9, 16, 25, so guess 1 + 3 + ⋯ + (2n − 1) = n². The inductive step is one line: [1 + 3 + ⋯ + (2k − 1)] + (2k + 1) = k² + 2k + 1 = (k + 1)². The bracket is replaced using the hypothesis.

Examples 3–4: inequalities

n < 2ⁿ: from k < 2ᵏ and 1 ≤ 2ᵏ, k + 1 < 2ᵏ + 2ᵏ = 2ᵏ⁺¹.

2ⁿ < n! for n ≥ 4 (false for n = 1, 2, 3, so the basis is P(4): 16 < 24). Step: 2ᵏ⁺¹ = 2·2ᵏ < 2·k! < (k + 1)·k! = (k + 1)!, because 2 < k + 1.

Example 5: sets

A set with n ≥ 0 elements has 2ⁿ subsets. Basis: ∅ has 2⁰ = 1 subset. Step: write T = S ∪ {a} with |S| = k. Every subset X of S gives exactly two subsets of T, namely X and X ∪ {a}, so T has 2·2ᵏ = 2ᵏ⁺¹ subsets.

4.2Strong induction

Principle II (SI)

Basis step. Show that P(1) is true.
Inductive step. Show that [P(1) ∧ P(2) ∧ ⋯ ∧ P(k)] → P(k + 1) for every positive integer k.

The hypothesis is stronger: you may use every earlier case, not only P(k). Theorem 1 shows that SI and RI are equivalent, so whatever one proves, the other proves too; SI is just more convenient when P(k + 1) depends on a case further back.

Alternative form

To prove P(n) for all n ≥ b: check the basis cases P(b), P(b + 1), …, P(b + j), then show [P(b) ∧ ⋯ ∧ P(k)] → P(k + 1) for every k ≥ b + j. You need several basis cases when the step reaches back several places: a step that uses P(k − 2) needs three of them.

Example 6: prime factors

Every integer n > 1 is a product of primes. Basis: 2 is prime. Step: if k + 1 is prime, done. Otherwise k + 1 = ab with 2 ≤ a ≤ b < k + 1. By the strong hypothesis both a and b are products of primes, so k + 1 is too. Regular induction would only give you P(k), which says nothing about a or b.

Examples 8–9: stamps and bills

Two- and five-dollar bills form every amount n ≥ 4. Basis: 4 = 2 + 2, 5 = 5, 6 = 2 + 2 + 2. Step for k ≥ 6: k − 1 ≥ 5 can be formed by the hypothesis; add a 2-dollar bill. (Two basis cases would be enough here; three are harmless.)

Three- and five-cent stamps form every postage n ≥ 8. Basis: 8 = 3 + 5, 9 = 3 + 3 + 3, 10 = 5 + 5. Step for k ≥ 10: form k − 2, then add a 3-cent stamp.

4.3What the steps really prove

Example 10

Read the inductive step as a set of arrows and follow them from the basis:

  • P(1) and P(n) → P(n + 2): only P(1), P(3), P(5), …
  • P(1) and P(n) → P(2n): only P(1), P(2), P(4), P(8), …
  • P(1), P(2) and P(n) ∧ P(n + 1) → P(n + 2): every n (strong induction).
Broken proofs

All horses have the same colour (Example 11). The step says that the first k and the last k of k + 1 horses overlap. For k + 1 = 2 they do not, so P(1) → P(2) is false and the chain breaks at its first link.

5n = 0 for every n ≥ 0 (Example 12). The step writes k + 1 = i + j with i, j < k + 1. For k + 1 = 1 this needs i = 0 and j = 1, and j = 1 is not smaller than k + 1. Check that the step works for the smallest k, including k = b.

4.4The well-ordering property

Axioms A1–A4

The positive integers ℕ are the subset of ℤ with: (A1) 1 ∈ ℕ; (A2) n ∈ ℕ ⟹ n + 1 ∈ ℕ; (A3) every element other than 1 is a successor; (A4, WOP) every nonempty subset of ℕ has a least element. The same holds for nonempty subsets of ℕ ∪ {0}.

Theorems 1–2 of Lecture 7 show that WOP and MI imply each other. Together with Lecture 6: SI ⟺ MI ⟺ WOP.

Template for a WOP proof (by contradiction)

  1. Let C = {n ∈ ℕ | ¬P(n)} be the set of counterexamples.
  2. Assume C ≠ ∅.
  3. By the WOP, C has a least element m.
  4. Reach a contradiction: show that P(m) is true after all, or find a counterexample smaller than m. This is the creative part.
  5. Conclude that C = ∅: P(n) holds for every n.
Example 1: the division algorithm

For an integer a and d > 0 there are unique q, r with a = dq + r and 0 ≤ r < d. Existence: S = {a − dq ≥ 0 | q ∈ ℤ} is nonempty, so it has a least element r = a − dq₀ ≥ 0. If r ≥ d, then r − d = a − d(q₀ + 1) would be a smaller element of S. So r < d. Uniqueness: two such pairs give d(q − q′) = r′ − r with −d < r′ − r < d, so r′ = r and q′ = q.

Watch negative a: −17 = 5·(−4) + 3, so q = −4 and r = 3, not q = −3, r = −2.

Example 4: find the least element

The WOP says a least element exists; finding it takes algebra. For S = {n ∈ ℕ | n = x² − 8x + 12, x ∈ ℤ}: x² − 8x + 12 = (x − 2)(x − 6) > 0 exactly when x < 2 or x > 6. The values closest to the roots are x = 1 and x = 7, both giving 5. So min S = 5.

Examples 5–7

f(0) = 2, f(n + 1) = 3f(n) − 2 gives f(1) = 4, f(2) = 10, f(3) = 28, f(4) = 82. Powers: a⁰ = 1, aⁿ⁺¹ = a·aⁿ. Partial sums: S(0) = a₀, S(n + 1) = S(n) + aₙ₊₁.

Fibonacci (Exercise 1.8): F(0) = 0, F(1) = 1, F(n) = F(n − 1) + F(n − 2) for n > 1. The value depends on two earlier values; strong induction shows such definitions are well defined.

Sets and strings

Example 8. 3 ∈ S; if x, y ∈ S then x + y ∈ S. This produces 3, 6, 9, 12, …, the positive multiples of 3 (Example 11). The exclusion rule says that nothing else is in S.

Strings over an alphabet Σ (Definition 5): λ ∈ Σ* (the empty string); if w ∈ Σ* and x ∈ Σ, then wx ∈ Σ*. For Σ = {0, 1} the first steps give λ; then 0, 1; then 00, 01, 10, 11.

Length (Definition 7): l(λ) = 0, l(wx) = l(w) + 1. Concatenation (Definition 6): wλ = w, w₁(w₂x) = (w₁w₂)x.

4.6Structural induction

Definition 8

Basis step. Show the statement for every element put into the set by the basis step of the definition.
Recursive step. Show that if the statement holds for the elements used to build a new element, it holds for the new element.

For strings: show P(λ); then assume P(w) and show P(wx) for every x ∈ Σ. It is valid because it is ordinary induction on the number of times the recursive rule was used (Theorem 3).

Example 11: two inclusions

To show S = A (with A the positive multiples of 3), prove both inclusions. A ⊆ S by MI on n: 3·1 ∈ S, and 3k ∈ S, 3 ∈ S give 3k + 3 ∈ S. S ⊆ A by structural induction: 3 ∈ A, and if 3 | x and 3 | y then 3 | x + y.

Example 12

l(xy) = l(x) + l(y), by structural induction on y. Basis: l(xλ) = l(x) = l(x) + 0 = l(x) + l(λ). Step: assume l(xy) = l(x) + l(y). Then l(xya) = l(xy) + 1 = l(x) + l(y) + 1 = l(x) + l(ya). ∎

P8.1

Puzzle: the sum of the first odd numbers

Put the steps of the proof of 1 + 3 + ⋯ + (2n − 1) = n² for all n ≥ 1 in order. (Example 2.)

  1. Let P(n) be the statement 1 + 3 + ⋯ + (2n − 1) = n².
  2. Basis step: P(1) says 1 = 1², which is true.
  3. Inductive step: assume 1 + 3 + ⋯ + (2k − 1) = k² for an arbitrary k ≥ 1.
  4. We must show 1 + 3 + ⋯ + (2k − 1) + (2k + 1) = (k + 1)².
  5. By the hypothesis the left side equals k² + (2k + 1) = (k + 1)², so P(k + 1) is true.
  6. By mathematical induction, P(n) is true for every positive integer n. ∎
P8.2

Where does the basis start?

Each claim holds for all n ≥ b and fails for n = b − 1 (among positive integers). Find b.

  1. 2ⁿ < n!
  2. 3ⁿ < n! (Exercise 2.18)
  3. n² < 2ⁿ
  4. 2n + 3 ≤ 2ⁿ
Hint

Make a small table of both sides for n = 1, …, 8. In (c), n = 1 also works, but n = 2, 3, 4 do not.

Answer

(a) 16 < 24 at n = 4, but 8 > 6 at n = 3: b = 4.

(b) 3⁶ = 729 > 720 = 6!, 3⁷ = 2187 < 5040 = 7!: b = 7. Step: 3ᵏ⁺¹ = 3·3ᵏ < 3·k! < (k + 1)·k!, since k + 1 > 3.

(c) 16 = 16 at n = 4 is not strict; 25 < 32 at n = 5: b = 5.

(d) 9 > 8 at n = 3, 11 ≤ 16 at n = 4: b = 4.

P8.3

Even numbers and a step of three

Prove by induction (Exercises 2.3 and 2.4):

  1. 2 + 4 + 6 + ⋯ + 2n = n(n + 1)
  2. 1 + 4 + 7 + ⋯ + (3n − 2) = n(3n − 1)/2
Model proof

(a) Basis: 2 = 1·2. Step: assume 2 + ⋯ + 2k = k(k + 1). Then 2 + ⋯ + 2k + 2(k + 1) = k(k + 1) + 2(k + 1) = (k + 1)(k + 2), which is P(k + 1). ∎

(b) Basis: 1 = 1·2/2. Step: assume the formula for k. The next term is 3(k + 1) − 2 = 3k + 1, and

k(3k − 1)/2 + (3k + 1) = (3k² − k + 6k + 2)/2 = (3k² + 5k + 2)/2 = (k + 1)(3k + 2)/2 = (k + 1)(3(k + 1) − 1)/2. ∎

P8.4

The sum of squares

Prove that 1² + 2² + ⋯ + n² = n(n + 1)(2n + 1)/6 for every n ≥ 1 (Exercise 2.5). Then use it: what is 1² + 2² + ⋯ + 10²?

Hint

In the step, factor (k + 1) out of k(k + 1)(2k + 1)/6 + (k + 1)² before you expand anything.

Model proof

Basis: 1 = 1·2·3/6. Step: assume the formula for k. Then

1² + ⋯ + k² + (k + 1)² = k(k + 1)(2k + 1)/6 + (k + 1)² = (k + 1)[k(2k + 1) + 6(k + 1)]/6 = (k + 1)(2k² + 7k + 6)/6 = (k + 1)(k + 2)(2k + 3)/6,

which is the formula for n = k + 1, because 2(k + 1) + 1 = 2k + 3. ∎ For n = 10: 10·11·21/6 = 385.

P8.5

Divisibility

Prove for every positive integer n:

  1. 5 | 7ⁿ − 2ⁿ (Exercise 2.8)
  2. 3 | n³ − 4n + 6 (Exercise 2.9)
  3. 21 | 4ⁿ⁺¹ + 5²ⁿ⁻¹ (Exercise 2.19)
Hint

Write the (k + 1) expression as a multiple of the k expression plus something visibly divisible. For (a): 7ᵏ⁺¹ − 2ᵏ⁺¹ = 7(7ᵏ − 2ᵏ) + 5·2ᵏ.

Model proof

(a) Basis: 7 − 2 = 5. Step: 7ᵏ⁺¹ − 2ᵏ⁺¹ = 7·7ᵏ − 2·2ᵏ = 7(7ᵏ − 2ᵏ) + 5·2ᵏ. The first term is divisible by 5 by the hypothesis, the second obviously. ∎

(b) Basis: 1 − 4 + 6 = 3. Step: (k + 1)³ − 4(k + 1) + 6 = (k³ − 4k + 6) + 3k² + 3k − 3 = (k³ − 4k + 6) + 3(k² + k − 1). Both parts are divisible by 3. ∎

(c) Basis: 4² + 5 = 21. Step: 4ᵏ⁺² + 5²ᵏ⁺¹ = 4·4ᵏ⁺¹ + 25·5²ᵏ⁻¹ = 4(4ᵏ⁺¹ + 5²ᵏ⁻¹) + 21·5²ᵏ⁻¹. Both parts are divisible by 21. ∎

P8.6

Factorials and Bernoulli's inequality

  1. Prove 1·1! + 2·2! + ⋯ + n·n! = (n + 1)! − 1 for n ≥ 1 (Exercise 2.12).
  2. Prove that if h > −1, then 1 + nh ≤ (1 + h)ⁿ for all n ≥ 0 (Exercise 2.13).
Model proof

(a) Basis: 1·1! = 1 = 2! − 1. Step: (k + 1)! − 1 + (k + 1)(k + 1)! = (k + 1)!(1 + k + 1) − 1 = (k + 2)! − 1. ∎

(b) Basis: n = 0 gives 1 ≤ 1. Step: assume 1 + kh ≤ (1 + h)ᵏ. Because 1 + h > 0, multiplying by it keeps the inequality:

(1 + h)ᵏ⁺¹ ≥ (1 + kh)(1 + h) = 1 + (k + 1)h + kh² ≥ 1 + (k + 1)h. ∎

The condition h > −1 is used exactly once: to multiply an inequality by 1 + h.

P8.7

Counting subsets

Lecture 6 proves by induction that an n-element set has n(n − 1)/2 two-element subsets (Exercise 1.3), and asks you to prove that it has n(n − 1)(n − 2)/6 three-element subsets (Exercise 2.22). Use the formulas:

  1. How many two-element subsets does a 10-element set have?
  2. How many three-element subsets does a 7-element set have?
  3. How many subsets does a 7-element set have in all?
Solution

(a) 10·9/2 = 45 (b) 7·6·5/6 = 35 (c) 2⁷ = 128 (Example 5).

Proof of the three-element formula: fix a ∈ S with |S| = k + 1 and T = S ∖ {a}. A three-element subset either avoids a (one of the k(k − 1)(k − 2)/6 subsets of T, by the hypothesis) or contains a and two elements of T (k(k − 1)/2 ways, by Exercise 1.3). The sum is k(k − 1)(k − 2)/6 + 3k(k − 1)/6 = (k + 1)k(k − 1)/6. ∎

P8.8

Stamps of 4 and 7 cents

Exercise 2.24 (the second one) outlines a strong induction proof that postage of n ≥ 18 cents can be formed from 4-cent and 7-cent stamps.

  1. Which amounts from 1 to 17 cents can not be formed?
  2. Give the basis cases P(18), …, P(21).
  3. Which earlier case does the inductive step use for P(k + 1), k ≥ 21? Complete the step.
  4. Using the same idea, what is the largest amount that cannot be formed from 3-cent and 7-cent stamps?
Hint

Adding one 4-cent stamp moves you up by 4, so the step reaches back 4 places. That is why four basis cases are needed.

Solution

(a) 4, 7, 8, 11, 12, 14, 15, 16 can be formed; the others, {1, 2, 3, 5, 6, 9, 10, 13, 17}, cannot. So 17 is the largest amount that cannot be formed, and the claim really starts at 18.

(b) 18 = 4 + 7 + 7, 19 = 4 + 4 + 4 + 7, 20 = 4·5, 21 = 7·3.

(c) Hypothesis: P(j) for 18 ≤ j ≤ k, with k ≥ 21. Then 18 ≤ k − 3 ≤ k, so k − 3 cents can be formed; add a 4-cent stamp to get k + 1. ∎

(d) With 3 and 7: 1, 2, 4, 5, 8 and 11 cannot be formed, while 12, 13, 14 can (3·4, 3·2 + 7, 7·2), and adding 3-cent stamps reaches everything above. The largest impossible amount is 11.

P8.9

Which P(n) must be true?

Exercise 2.25. For each set of facts, list the n in {0, 1, …, 10} for which P(n) must be true.

  1. P(0); P(n) → P(n + 2)
  2. P(0); P(n) → P(n + 3)
  3. P(0), P(1); P(n) ∧ P(n + 1) → P(n + 2)
  4. P(0); P(n) → P(n + 2) ∧ P(n + 3)
Answer

(a) The even numbers. (b) The multiples of 3. (c) Every n, by strong induction. (d) From 0 you reach 2 and 3, then 4, 5, 6, and from then on everything; only P(1) is not forced. In general: every n ≠ 1.

P8.10

Find the flaw: all horses

Example 11: “Among any k + 1 horses, the first k have one colour and the last k have one colour. The two groups overlap, so all k + 1 have the same colour.”

Where does it break?

  • The basis step: P(1) is false
  • It uses strong induction where regular induction is needed
  • The step P(1) → P(2): two horses split into two groups of one that do not overlap
  • The step for large k: the groups overlap in too few horses

For k + 1 = 2 the “first one” and “last one” share no horse, so nothing links their colours. Every other step P(k) → P(k + 1) with k ≥ 2 is fine, but the chain is broken at its first link, so nothing follows.

P8.11

Find the flaw: max(x, y)

Exercise 2.26 “proves” that if max(x, y) = n for positive integers x, y, then x = y. Step: “if max(x, y) = k + 1, then max(x − 1, y − 1) = k, so x − 1 = y − 1 by the hypothesis.”

What is wrong?

  • The basis step: max(x, y) = 1 allows x ≠ y
  • The hypothesis is only about positive integers, but x − 1 or y − 1 may be 0
  • max(x − 1, y − 1) is k − 1, not k
  • Nothing: the claim is true

Take x = 1, y = 2: then max(x − 1, y − 1) = max(0, 1) = 1, but 0 is not a positive integer, so the hypothesis does not apply. The claim is false: max(1, 2) = 2 and 1 ≠ 2.

P8.12

Find the flaw: aⁿ = 1

Exercise 2.27, for a nonzero real a. Basis: a⁰ = 1. Step (strong): assume aʲ = 1 for all 0 ≤ j ≤ k; then aᵏ⁺¹ = aᵏ·aᵏ / aᵏ⁻¹ = 1·1/1 = 1.

Where is the error?

  • The basis: a⁰ is not defined
  • The algebra: aᵏ·aᵏ/aᵏ⁻¹ is not aᵏ⁺¹
  • Strong induction cannot be used for powers
  • The first step, k = 0: it uses a⁻¹, which is not covered by the hypothesis

For k = 0 the formula needs aᵏ⁻¹ = a⁻¹, and the hypothesis only covers j ≥ 0. So P(0) → P(1) is never proved, and indeed a¹ = a need not be 1. The algebra itself is correct.

P8.13

Find the flaw: stamps of 3 and 4 cents

Exercise 2.28 “proves” that every postage of 3 cents or more can be formed with 3- and 4-cent stamps. Basis: 3 and 4. Step: “form k cents, then replace one 3-cent stamp by a 4-cent stamp, or two 4-cent stamps by three 3-cent stamps.”

Which statement is right?

  • For k = 4 (a single 4-cent stamp) neither replacement is possible, and 5 cents really cannot be formed
  • The proof is correct; every amount from 3 on can be formed
  • The basis needs 3, 4 and 5 and then the step works
  • It fails only because strong induction was used

With one 4-cent stamp there is no 3-cent stamp to replace and not two 4-cent stamps to swap. The step P(4) → P(5) fails, and 5 cents is in fact impossible. A correct version: every amount from 6 cents on can be formed, by strong induction with basis 6, 7, 8 and the step from k − 2 to k + 1 (add a 3-cent stamp).

P8.14

True or false: the principles

  1. Induction is a good way to discover a formula.It only proves a formula you already have. Example 2 guesses n² from a table first.
  2. In the inductive step of RI we assume that P(k) is true for all k.We assume it for one arbitrary k and deduce P(k + 1). Assuming it for all k would assume the result.
  3. Strong induction can prove statements that regular induction cannot.Theorem 1 of Lecture 6: the two principles are equivalent. SI is only more convenient.
  4. A strong induction proof whose step uses P(k − 2) needs three basis cases.Each of the three residues must be started, as in Example 9: P(8), P(9), P(10).
  5. The basis step may be P(0) or even P(−3).The base b can be any integer; the step is then proved for every k ≥ b.
  6. If the inductive step is correct, the basis step can be skipped.Without a basis the chain has nowhere to start. P(n): “n = n + 1” has a valid step P(k) → P(k + 1), but it is false for every n.

Least elements

By the WOP each set has a least element. Find it (x ranges over ℤ).

  2. {n ∈ ℕ | n = x² − 10x + 28} (Exercise 2.1)

Solution

P9.3

Puzzle: every n > 1 has a prime divisor

Put the steps of the WOP proof in order (Exercise 1.1).

  1. Let S be the set of integers n > 1 with no prime divisor, and assume S ≠ ∅.
  2. By the WOP, S has a least element n.
  3. n is not prime, because a prime is its own prime divisor.
  4. So n has a divisor d with 1 < d < n.
  5. Since d < n is not in S, it has a prime divisor p.
  6. From p | d and d | n we get p | n, which contradicts n ∈ S.
  7. Hence S = ∅: every integer greater than 1 has a prime divisor. ∎
P9.4

Fill in the gaps: stamps of 10 and 15

Exercise 1.3: every postage made from 10- and 15-cent stamps is divisible by 5. Let m be the least counterexample. Then m − 10 or m − 15 can be made too (remove one stamp). Complete: “Suppose m − 10 can be made. Then 5 | m − 10, because … But then 5 | m, because …”

Model answer

“Then 5 | m − 10, because m − 10 < m can be made and m is the least counterexample, so m − 10 is not a counterexample.” (If m − 10 = 0, then m = 10 is divisible by 5 anyway.)

“Then 5 | m, because m = (m − 10) + 10 is a sum of two multiples of 5.” This contradicts the choice of m; the case m − 15 is the same with 15 in place of 10. ∎

P9.5

Find the flaw: every Fibonacci number is even

Exercise 1.8. The bogus WOP proof says: (6) m > 0, since F(0) = 0 is even. (7) Since m is the least counterexample, F(k) is even for all k < m. (8) In particular F(m − 1) and F(m − 2) are both even. (9) So F(m) = F(m − 1) + F(m − 2) is even.

Which sentence contains the error?

  • (6)
  • (7)
  • (8): for m = 1, m − 2 = −1 is not a nonnegative integer
  • (9)

The case m = 1 is never handled. There F(m − 2) does not exist, and the recursive rule F(n) = F(n − 1) + F(n − 2) applies only for n > 1, so (9) cannot be used either. In fact F(1) = 1 is odd: m = 1 is the least counterexample.

P9.7

Write a recursive definition

Give a basis step and a recursive step for:

  1. n! for n ≥ 0
  2. the sequence aₙ = 2n + 1, n ≥ 0
  3. the set of positive even integers
  4. the reversal wᴿ of a string w ∈ Σ* (for example (abc)ᴿ = cba)
Answer

(a) 0! = 1; (n + 1)! = (n + 1)·n!.

(b) a₀ = 1; aₙ₊₁ = aₙ + 2.

(c) 2 ∈ S; if x ∈ S then x + 2 ∈ S (or: if x, y ∈ S then x + y ∈ S).

(d) λᴿ = λ; (wx)ᴿ = x wᴿ for w ∈ Σ*, x ∈ Σ.

P9.9

Puzzle: the length of a concatenation

Put the steps of the structural induction proof of l(xy) = l(x) + l(y) in order (Example 12).

  1. Fix x ∈ Σ*; induct on y, using the recursive definition of Σ*.
  2. Basis step: l(xλ) = l(x) = l(x) + 0 = l(x) + l(λ).
  3. Recursive step: assume l(xy) = l(x) + l(y), and let a ∈ Σ.
  4. By the definition of length, l(xya) = l(xy) + 1.
  5. By the hypothesis, l(xy) + 1 = l(x) + l(y) + 1.
  6. By the definition of length again, l(y) + 1 = l(ya), so l(xya) = l(x) + l(ya). ∎
P9.10

Powers of k

Exercise 1.9: k ∈ S; if x, y ∈ S then xy ∈ S. Show S = A = {kⁿ | n ≥ 1}.

Model proof

S ⊆ A, by structural induction. Basis: k = k¹ ∈ A. Recursive step: if x, y ∈ S and, by the hypothesis, x = kp, y = kq with p, q ≥ 1, then xy = kp + q ∈ A.

A ⊆ S, by MI on n. Basis: k¹ = k ∈ S. Step: if kⁿ ∈ S, then kⁿ and k are both in S, so kⁿ·k = kⁿ⁺¹ ∈ S. ∎

P9.11

Reversal keeps the length

With the definition of P9.7(d), prove l(wᴿ) = l(w) for every w ∈ Σ*.

Hint

You need l(x wᴿ) = 1 + l(wᴿ). That is Example 12 with the one-letter string x in front: l(x wᴿ) = l(x) + l(wᴿ).

Model proof

Structural induction on w. Basis: l(λᴿ) = l(λ), since λᴿ = λ. Recursive step: assume l(wᴿ) = l(w) and let x ∈ Σ. Then

l((wx)ᴿ) = l(x wᴿ) = l(x) + l(wᴿ) = 1 + l(w) = l(wx),

using the definition of reversal, Example 12, the hypothesis, and the definition of length. ∎
