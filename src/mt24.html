V1 · 1

Minimal AND–OR circuit · 4 pt

Design a three-input minimal AND–OR circuit L with truth table T[x, y, z; L] = [00001111, 00110011, 01010101; 10011011].

Solution

Step 1: positions 1, 4, 5, 7, 8 give L = x′y′z′ + x′yz + xy′z′ + xyz′ + xyz.

Steps 2–3: y′z′ and yz are essential; xyz′ goes with xy or xz′:

L = y′z′ + yz + xy or L = y′z′ + yz + xz′

V1 · 2

Truth table of an expression · 5 pt

Find T(E) for E = (x′y + z)′(x′ + y′z) + (x′z + y)(y′z)′ + xz′ + x′y′z. Step 1: an SoP form (3 pt). Step 2: the CSoP form (1 pt). Step 3: T(E) (1 pt).

Hint

(x′y + z)′ = (x + y′)z′ and (y′z)′ = y + z′. The first product collapses to a single minterm.

Solution

(x + y′)z′(x′ + y′z) = xz′x′ + xz′y′z + y′z′x′ + y′z′y′z = x′y′z′

(x′z + y)(y + z′) = x′yz + x′zz′ + y + yz′ = x′yz + y

So E = x′y′z′ + x′yz + y + xz′ + x′y′z = x′y′ + xz′ + y.

CSoP: every minterm except xy′z: x′y′z′ + x′y′z + x′yz′ + x′yz + xy′z′ + xyz′ + xyz. Only position 6 is 0, so T(E) = 11111011.

Not asked, but since E′ = xy′z, the shortest form is E = x′ + y + z′.

  2. ∃!x(x² = 1)Two solutions: x = 1 and x = −1.

V1 · 6

Infinite sets · 2 pt

Prove that every infinite set is equivalent to one of its proper subsets.

Hint

Every infinite set contains a countable subset {a₁, a₂, a₃, …}. Shift it into its odd-numbered elements and leave everything else where it is.

Model proof

Let M be infinite. It contains a countable subset A = {a₁, a₂, a₃, …} with all aₙ distinct. Split it as A₁ = {a₁, a₃, a₅, …} and A₂ = {a₂, a₄, a₆, …}.

Define f : M → M ∖ A₂ by f(aₙ) = a₂ₙ₋₁ on A and f(x) = x for x ∈ M ∖ A. It maps A one-to-one onto A₁ and fixes M ∖ A, so it is a bijection from A ∪ (M ∖ A) = M onto A₁ ∪ (M ∖ A) = M ∖ A₂.

So M ∼ M ∖ A₂, and M ∖ A₂ is a proper subset of M because a₂ ∉ M ∖ A₂. ∎

V1 · 7

De Morgan for union · 1 pt

Let A, B ⊆ S. Prove (A ∪ B)′ = A′ ∩ B′.

Model proof

For every x ∈ S:

x ∈ (A ∪ B)′ ⟺ x ∉ A ∪ B ⟺ ¬(x ∈ A ∨ x ∈ B) ⟺ x ∉ A ∧ x ∉ B ⟺ x ∈ A′ ∧ x ∈ B′ ⟺ x ∈ A′ ∩ B′.

So the two sets have the same elements. ∎

V2 · 2

Truth table of an expression · 5 pt

Find T(E) for E = ((x + y)′ + z)′(x′ + yz′)′ + (xy + z′)′(yz′) + x′z + x′yz′.

Hint

Apply De Morgan twice to the first factor: ((x + y)′ + z)′ = (x + y)z′. In the second product, look at z against z′.

Solution

((x + y)′ + z)′ = (x + y)z′ and (x′ + yz′)′ = x(y′ + z), so (xz′ + yz′)(xy′ + xz) = xy′z′ + xzz′ + xyy′z′ + xyzz′ = xy′z′.

(xy + z′)′ = (x′ + y′)z, and (x′ + y′)z · yz′ = 0 because of zz′.

So E = xy′z′ + x′z + x′yz′. CSoP: xy′z′ + x′yz + x′y′z + x′yz′, positions 5, 4, 2, 3, so T(E) = 01111000.

Rational intervals · 2 pt

Prove that the set of all rational intervals on the line ℝ is countable. (An interval is rational if both its end points are rational.)

Hint

Fix the left end point r₁. How many intervals start there? Then let r₁ run through ℚ.

Model proof

An interval is determined by its end points, so the set is A = {(r₁, r₂) : r₁, r₂ ∈ ℚ, r₁ < r₂}.

For each r₁ ∈ ℚ let A(r₁) = {(r₁, r₂) : r₂ ∈ ℚ, r₂ > r₁}. The map (r₁, r₂) ↦ r₂ is a bijection from A(r₁) onto {q ∈ ℚ : q > r₁}, an infinite subset of the countable set ℚ. So each A(r₁) is countable.

Every interval lies in exactly one family, so A = ⋃r₁∈ℚ A(r₁): a union of countably many countable sets. Hence A is countable. ∎

The same argument works for closed or half-open intervals: each kind is countable, and a union of four countable sets is countable.

De Morgan for intersection · 1 pt

Let A, B ⊆ S. Prove (A ∩ B)′ = A′ ∪ B′.

Model proof

For every x ∈ S:

x ∈ (A ∩ B)′ ⟺ x ∉ A ∩ B ⟺ ¬(x ∈ A ∧ x ∈ B) ⟺ x ∉ A ∨ x ∉ B ⟺ x ∈ A′ ∨ x ∈ B′ ⟺ x ∈ A′ ∪ B′.

So the two sets have the same elements. ∎
