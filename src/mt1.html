Midterm 1 practice (Fall 2025)

Last year's Midterm 1 came in two variants with the same seven tasks: K-map circuit design, a truth table from an expression, an MSoP from a truth table, two 4-variable K-maps, a De Morgan proof, quantifiers, and a countability proof. Work through one variant under exam conditions (about 75 minutes), check it here, then do the other.

How the exam is marked

  • Truth tables use the special sequences x = 00001111, y = 00110011, z = 01010101. Position 1 is x′y′z′ and position 8 is xyz.
  • Tasks 1–3 give marks for each step: CSoP (or SoP), then the K-map, then the MSoP, then the circuit. Show every step.
  • When a function has several minimal sums, one of them is enough.
  • Task 7 must be a proof, not an explanation (“A student may submit another proof. But it must be ‘proof’ that is not an explanation.”).

Variant 1

V1 · 1

Minimal AND–OR circuit · 4 pt

Design a three-input minimal AND–OR circuit L with truth table T[x, y, z; L] = [00001111, 00110011, 01010101; 10011011].

Hint

The 1s are in positions 1, 4, 5, 7, 8. Read each position as a minterm from Table 1, then look for pairs on the map, remembering that the left and right columns are adjacent.

Solution

Step 1: L = x′y′z′ + x′yz + xy′z′ + xyz′ + xyz.

Steps 2–3: x′y′z′ + xy′z′ = y′z′ and x′yz + xyz = yz are essential. The square xyz′ is left; it pairs with xyz (xy) or with xy′z′ (xz′). Two minimal sums, 3 products and 6 literals each:

L = y′z′ + yz + xy or L = y′z′ + yz + xz′

V1 · 2

Truth table of an expression · 5 pt

Find T(E) for E = (xy′ + z′)′(x + yz′) + (x′z + y)(y′z)′ + x′z + xy′z′. Step 1: an SoP form (3 pt). Step 2: the CSoP form (1 pt). Step 3: T(E) (1 pt).

Hint

De Morgan on the two complemented factors first: (xy′ + z′)′ = (x′ + y)z and (y′z)′ = y + z′. Then multiply out and use y + yz′ = y and y + xyz = y.

Solution

(xy′ + z′)′(x + yz′) = (x′ + y)z(x + yz′) = x′zx + x′zyz′ + yzx + yzyz′ = xyz

(x′z + y)(y′z)′ = (x′z + y)(y + z′) = x′yz + x′zz′ + y + yz′ = x′yz + y

So E = xyz + x′yz + y + x′z + xy′z′ = y + x′z + xy′z′ (absorption).

CSoP: y(x + x′)(z + z′) + x′(y + y′)z + xy′z′ = xyz + xyz′ + x′yz + x′yz′ + x′y′z + xy′z′.

T(E): the minterms sit in positions 8, 7, 4, 3, 2, 5, so T(E) = 01111011.

Not asked, but the map shrinks it further to y + x′z + xz′.

V1 · 5

De Morgan for union · 2 pt

Let A, B ⊆ S. Prove (A ∪ B)′ = A′ ∩ B′.

Model proof

For every x ∈ S:

x ∈ (A ∪ B)′ ⟺ x ∉ A ∪ B ⟺ ¬(x ∈ A ∨ x ∈ B) ⟺ x ∉ A ∧ x ∉ B ⟺ x ∈ A′ ∧ x ∈ B′ ⟺ x ∈ A′ ∩ B′.

The third step is De Morgan's law for propositions. Both sets have the same elements, so they are equal. ∎

The sheet writes U − (A ∪ B) in the second step; here the universal set is called S.

Quantifiers · 2 pt

6.1 The negation of ∃x ∃y ∀z P(x, y, z) is

  • ∃x ∃y ∀z ¬P(x, y, z)
  • ∀x ∀y ∀z ¬P(x, y, z)
  • ∀x ∀y ∃z ¬P(x, y, z)
  • ∀x ∃y ∃z ¬P(x, y, z)

Push ¬ inwards one quantifier at a time, flipping each: ∀x ¬∃y ∀z P = ∀x ∀y ¬∀z P = ∀x ∀y ∃z ¬P.

  4. ∃x(2x = 4x + 2)x = −1.
V1 · 7

Polynomials with rational coefficients · 2 pt

Using “a finite or countable union of countable sets is countable”, prove that the set P of all polynomials with rational coefficients is countable.

Hint

Split P by degree, and show each piece is countable by induction on the degree.

Model proof

Let Aₙ be the set of polynomials of degree exactly n (put the constants, including 0, in A₀). Then P = A₀ ∪ A₁ ∪ A₂ ∪ ⋯, a countable union, so it is enough to show each Aₙ is countable.

Let Bₙ = A₀ ∪ ⋯ ∪ Aₙ be the polynomials of degree at most n. B₀ = A₀ = ℚ is countable. Suppose Bₙ₋₁ is countable. For each a ∈ ℚ, the set {a xⁿ + q : q ∈ Bₙ₋₁} is in bijection with Bₙ₋₁, hence countable. Then Bₙ = ⋃a∈ℚ {a xⁿ + q : q ∈ Bₙ₋₁} is a countable union of countable sets, so it is countable. By induction every Bₙ is countable, and Aₙ ⊆ Bₙ is infinite (it contains xⁿ + q for every q ∈ ℚ), so it is countable too. ∎

The sheet's proof fixes aₙ, …, a₁, lets a₀ run through ℚ, then frees a₁, and so on: the same induction, written out step by step. It writes P = ∑ Aₙ for the disjoint union ⋃ Aₙ. Another route: aₙxⁿ + ⋯ + a₀ ↦ (aₙ, …, a₀) is a bijection from Aₙ onto a subset of ℚⁿ⁺¹, which is countable.

V2 · 2

Truth table of an expression · 5 pt

Find T(E) for E = (xy + z′)(x + y′z′)′ + (xy′ + z)′(yz′)′ + x′y + x′yz′.

Solution

(x + y′z′)′ = x′(y + z), so (xy + z′)x′(y + z) = xyx′y + xyx′z + x′yz′ + x′zz′ = x′yz′.

(xy′ + z)′ = (x′ + y)z′ and (yz′)′ = y′ + z, so (x′ + y)z′(y′ + z) = x′y′z′ + x′z′z + yy′z′ + yz′z = x′y′z′.

So E = x′yz′ + x′y′z′ + x′y + x′yz′ = x′y′z′ + x′y. CSoP: x′y′z′ + x′yz + x′yz′, positions 1, 4, 3, so T(E) = 10110000.

V2 · 5

De Morgan for intersection · 2 pt

Let A, B ⊆ S. Prove (A ∩ B)′ = A′ ∪ B′.

Model proof

For every x ∈ S:

x ∈ (A ∩ B)′ ⟺ x ∉ A ∩ B ⟺ ¬(x ∈ A ∧ x ∈ B) ⟺ x ∉ A ∨ x ∉ B ⟺ x ∈ A′ ∨ x ∈ B′ ⟺ x ∈ A′ ∪ B′.

So the two sets have the same elements. ∎

V2 · 7

Rational points of the plane · 2 pt

Prove that the set of all points of the plane with rational coordinates is countable.

Model proof

The set is A = ℚ × ℚ. For each a ∈ ℚ let Bₐ = {(a, y) : y ∈ ℚ}. The map y ↦ (a, y) is a bijection ℚ → Bₐ, so each Bₐ is countable. Every point (x, y) lies in exactly one of them, Bₓ, so A = ⋃a∈ℚ Bₐ, a union of countably many countable sets. Hence A is countable; it is infinite, since it contains B₀. ∎
