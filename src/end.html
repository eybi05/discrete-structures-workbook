Before the exam

Last-minute sheet

Sets

  • A = B ⟺ A ⊆ B and B ⊆ A
  • A ⊆ B ⟺ A ∩ B = A ⟺ A ∪ B = B
  • A ∖ B = A ∩ B′, A ⊕ B = (A ∖ B) ∪ (B ∖ A)
  • |P(S)| = 2ⁿ; n sets give 2ⁿ fundamental products
  • f(A ∩ B) ⊆ f(A) ∩ f(B) only

Functions and size

  • Each preimage has at most 1 (injective), at least 1 (onto), exactly 1 (bijective) element
  • Countable = can be listed; ℤ, ℚ are countable
  • [0, 1], ℝ are uncountable (diagonal argument)
  • ℵ₀ < c, |M| < |P(M)|
  • Infinite ⟺ equivalent to a proper subset

Connectives

  • p → q is false only for T → F
  • p → q ≡ ¬p ∨ q ≡ ¬q → ¬p
  • ¬(p → q) ≡ p ∧ ¬q
  • p ↔ q ≡ (p ∧ q) ∨ (¬p ∧ ¬q), p ⊕ q ≡ ¬(p ↔ q)
  • “p only if q” is p → q

Quantifiers

  • ¬∀x P ≡ ∃x ¬P, ¬∃x P ≡ ∀x ¬P
  • ∀ goes with →, ∃ goes with ∧
  • Finite domain: ∀ is a big ∧, ∃ a big ∨
  • ∀x∃y and ∃y∀x are different
  • Negate nested: flip every quantifier, negate the predicate

Boolean algebra

  • Axioms: commutative, distributive (both), identity, complement
  • Dual: swap + ↔ · and 0 ↔ 1
  • a + ab = a, a + a′b = a + b, xx′ = 0, xx = x
  • SoP: no product contained in another; CSoP: all minterms
  • Minimal sum = sum of prime implicants

K-maps and truth tables

  • 1, 2, 4, 8 squares give 4, 3, 2, 1 literals (4 variables)
  • Edges wrap; the four corners form yt
  • Take essential primes first, then the fewest, largest rectangles
  • x = 00001111, y = 00110011, z = 01010101
  • A 1 in position k is the minterm of k − 1 in binary

Induction

  • RI: basis P(b); step P(k) → P(k + 1) for every k ≥ b
  • SI: step P(b) ∧ ⋯ ∧ P(k) → P(k + 1); a step back j places needs j basis cases
  • Name P(n), label the hypothesis, show where you use it
  • Check the step at the smallest k (horses fail at k + 1 = 2)
  • SI ⟺ MI ⟺ WOP

WOP and recursion

  • WOP: set of counterexamples, least element m, contradiction
  • a = dq + r, 0 ≤ r < d, even for negative a
  • Recursive definition = basis step + recursive step (+ exclusion rule)
  • Strings: λ ∈ Σ*; w ∈ Σ*, x ∈ Σ ⟹ wx ∈ Σ*
  • Structural induction: basis elements, then each rule
  • Set equality: S ⊆ A by structural induction, A ⊆ S by MI
