Lectures 10–11

Relations

A relation is just a set of ordered pairs, so everything from Lecture 1 applies: relations can be united, intersected and complemented. Lectures 10–11 add what is special about pairs: pictures (matrices and directed graphs), the four properties reflexive, symmetric, antisymmetric and transitive, composition, closures, and equivalence relations, which are the same thing as partitions.

6.1Relations and their pictures

Definition 1

A binary relation from A to B is a subset R ⊆ A × B. Write aRb when (a, b) ∈ R. The domain is the set of first elements of the pairs in R, the range the set of second elements. A relation from A to itself is a relation on A.

Special relations on A: the diagonal (identity) ΔA = {(a, a) | a ∈ A}, the universal relation A × A and the empty relation ∅.

A function f: A → B is a relation in which every a ∈ A is the first element of exactly one pair: its graph.

Example 4: how many relations?

A × A has n² elements when |A| = n, and every subset is a relation, so there are 2n² relations on A: 2⁹ = 512 on {a, b, c}. From {a, b, c} to {1, 2} there are 2⁶ = 64 (Exercise 1).

6.2Properties of relations

Definitions 2–4: a relation R on A is

reflexive if (a, a) ∈ R for every a ∈ A, that is, ΔA ⊆ R;

symmetric if (a, b) ∈ R implies (b, a) ∈ R;

antisymmetric if (a, b) ∈ R and (b, a) ∈ R imply a = b: no two distinct elements are related both ways;

transitive if (a, b) ∈ R and (b, c) ∈ R imply (a, c) ∈ R.

6.3Combining relations

Definitions 5–7

Relations from A to B are sets, so R₁ ∪ R₂, R₁ ∩ R₂, R₁ − R₂ and the complement R′ = (A × B) − R are relations too.

The inverse is R⁻¹ = {(b, a) | (a, b) ∈ R}: reverse every pair (every arrow). (R⁻¹)⁻¹ = R, and the domain and range swap.

For R from A to B and S from B to C, the composite is S∘R = {(a, c) | there is a b with (a, b) ∈ R and (b, c) ∈ S}. R is applied first, as with functions. Composition is associative: T∘(S∘R) = (T∘S)∘R (Theorem 1).

Powers: R¹ = R, Rⁿ⁺¹ = Rⁿ∘R. (a, b) ∈ Rⁿ exactly when there is a path of length n from a to b (Theorem 3).

Three ways to compute S∘R

1. Middle elements. For each (a, b) ∈ R, list every (b, c) ∈ S and write down (a, c).

2. Arrow diagrams. Draw R and S side by side; (a, c) ∈ S∘R when an arrow of R followed by one of S leads from a to c.

3. Matrices. Multiply MR·MS (rows of R times columns of S). The nonzero entries are the pairs of S∘R; an entry counts the paths. Note the order: MR comes first.

Example 16

R = {(1, 1), (1, 4), (2, 3), (3, 1), (3, 4)}, S = {(1, 0), (2, 0), (3, 1), (3, 2), (4, 1)}. From 1: 1 → 1 → 0 and 1 → 4 → 1. From 2: 2 → 3 → 1, 2. From 3: 3 → 1 → 0 and 3 → 4 → 1. So S∘R = {(1, 0), (1, 1), (2, 1), (2, 2), (3, 0), (3, 1)}.

Theorem 2

R is transitive if and only if Rⁿ ⊆ R for every n ≥ 1. In practice: R is transitive exactly when R² ⊆ R. The “only if” half is an induction on n.

6.4Closures

Definition 9 and Theorems 4–6

The P-closure of R is the smallest relation with property P that contains R.

reflexive(R) = R ∪ ΔA: add the missing loops.

symmetric(R) = R ∪ R⁻¹: add the missing return arrows.

transitive(R) = R* = R ∪ R² ∪ R³ ∪ ⋯, the connectivity relation: (a, b) is in it when some path leads from a to b. On a set of n elements a shortest path never needs more than n steps (Lemma 1, by the pigeonhole principle), so transitive(R) = R ∪ R² ∪ ⋯ ∪ Rⁿ.

Examples 19 and 23

R = {(1, 1), (1, 3), (2, 4), (3, 1), (3, 3), (4, 3)} on {1, 2, 3, 4}: reflexive(R) = R ∪ {(2, 2), (4, 4)} and symmetric(R) = R ∪ {(4, 2), (3, 4)}.

R = {(1, 2), (2, 3), (3, 3)} on {1, 2, 3}: R² = R³ = {(1, 3), (2, 3), (3, 3)}, so transitive(R) = {(1, 2), (1, 3), (2, 3), (3, 3)}.

Watch out

Closing under one property can destroy another: R = {(1, 2)} is transitive, but R ∪ R⁻¹ = {(1, 2), (2, 1)} is not, because (1, 1) is missing (Exercise 7(c)). When a problem asks for the smallest relation that is symmetric and transitive, take the symmetric closure first and then the transitive closure.

6.5Equivalence relations and partitions

Definitions 11–12

An equivalence relation is reflexive, symmetric and transitive. Examples: equality; “has the same length as” on strings (Example 25); congruence modulo m, a ≡ b (mod m) when m | a − b. Not an example: ⊆, which is not symmetric.

The equivalence class of a is [a] = {x | (a, x) ∈ R}; any element of [a] is a representative. The set of all classes is the quotient set S/R.

Theorem 7

If R is an equivalence relation on S, then S/R is a partition of S: (i) a ∈ [a]; (ii) [a] = [b] if and only if (a, b) ∈ R; (iii) if [a] ≠ [b], the classes are disjoint.

Conversely, every partition {Aᵢ} of S comes from the equivalence relation “a and b lie in the same block”, and its classes are the blocks.

Example 27 and Exercise 10

Congruence mod 5 splits ℤ into the five classes A₀, …, A₄, where Aᵣ holds the integers with remainder r; for instance A₂ = {…, −8, −3, 2, 7, 12, …}.

To find the classes of a finite relation, take an element not yet placed, collect everything related to it, and repeat. For the relation of Exercise 10 on {1, …, 6} this gives [1] = {1, 5}, [2] = {2, 3, 6}, [4] = {4}.

Template for “prove that R is an equivalence relation”

  1. Reflexive. Take an arbitrary a and show aRa.
  2. Symmetric. Assume aRb, write out what it means, and show bRa.
  3. Transitive. Assume aRb and bRc, write out both conditions, and combine them into aRc.
  4. Conclusion. “Hence R is an equivalence relation.”

Shortcut (Set 2, Exercise 10): if aRb means f(a) = f(b) for some function f, then R is an equivalence relation, and its classes are the nonempty preimages f⁻¹(y).

P12.11

Proofs: properties that survive intersection

  1. If every relation in a collection C on A is symmetric (transitive), then T = ∩C is symmetric (transitive). (Set 2, Exercise 4)
  2. If R is antisymmetric and S is any relation on A, then R ∩ S is antisymmetric. (Set 2, Exercise 6)
Model proof

(a) Symmetric: let (a, b) ∈ T. Then (a, b) ∈ S for every S ∈ C. Each S is symmetric, so (b, a) ∈ S for every S, that is, (b, a) ∈ T.

Transitive: let (a, b), (b, c) ∈ T. Both pairs lie in every S ∈ C; each S is transitive, so (a, c) lies in every S, that is, in T. ∎

(b) Let (a, b) ∈ R ∩ S and (b, a) ∈ R ∩ S. Then both pairs are in R, and R is antisymmetric, so a = b. ∎

This is why closures exist for symmetry and transitivity: the intersection of all symmetric (transitive) relations containing R is still symmetric (transitive), and it is the smallest one.

P13.8

Puzzle: ad = bc is an equivalence relation

Put the steps of Set 1, Exercise 9 in order: on pairs of nonzero integers, (a, b) ≈ (c, d) whenever ad = bc.

  1. Reflexive: (a, b) ≈ (a, b) because ab = ba.
  2. Symmetric: if ad = bc, then cb = da, which says (c, d) ≈ (a, b).
  3. Transitive: assume ad = bc and cf = de.
  4. Multiplying the two equations gives (ad)(cf) = (bc)(de).
  5. Cancel c ≠ 0 and d ≠ 0 to get af = be, that is, (a, b) ≈ (e, f).
  6. Hence ≈ is an equivalence relation. ∎
P13.9

Proof: a + d = b + c

On pairs of positive integers, ((a, b), (c, d)) ∈ R if and only if a + d = b + c (Set 2, Exercises 11 and 13).

  1. Prove that R is an equivalence relation.
  2. Describe the class of (1, 2). What does a class stand for?
Model proof

(a) a + d = b + c is the same as a − b = c − d, so R is “f(a, b) = f(c, d)” for f(x, y) = x − y, and every relation of this form is an equivalence relation (Set 2, Exercise 10).

Directly: reflexive, a + b = b + a. Symmetric, a + d = b + c gives c + b = d + a. Transitive, add a + d = b + c and c + f = d + e and cancel c + d: a + f = b + e. ∎

(b) [(1, 2)] = {(a, b) | a − b = −1} = {(1, 2), (2, 3), (3, 4), …}. Each class stands for one integer, the difference a − b; this is how the integers can be built from the positive integers.
