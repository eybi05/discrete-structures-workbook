Lectures 2–3

Propositions and quantifiers

Logic gives mathematical statements a precise meaning. Part 1 is the algebra of propositions (connectives, truth tables, equivalences). Part 2 adds predicates and the quantifiers ∀ and ∃.

2.1Propositions and connectives

Definition 1

A proposition is a declarative sentence that is either true (T) or false (F), but not both. “Baku is the capital of Azerbaijan” is true; “2 + 2 = 3” is false. Not propositions: questions (“What time is it?”), commands (“Do your homework.”), and open sentences such as x + 1 = 2, which get a truth value only once x is fixed or quantified.

A compound proposition is built from simpler ones with connectives; its truth value depends only on the truth values of the parts and on how they are connected.

→ if…then

↔ iff
true when both parts have the same truth value; p ↔ q ≡ (p → q) ∧ (q → p).
Watch out

A conditional with a false hypothesis is true. “If Aynur has a smartphone, then 2 + 3 = 6” is true when Aynur has no smartphone. A conditional says nothing about cause and effect.

Saying p → q

if p, then q · if p, q · q if p · q when p · q whenever p · p implies q · p only if q · p is sufficient for q · q is necessary for p · q follows from p · q unless ¬p

The two that cause mistakes: “p only if q” is p → q (not q → p), and “q unless ¬p” is also p → q. For p ↔ q: “p is necessary and sufficient for q”, “p iff q”.

Precedence

¬ first, then ∧, then ∨, then →, then ↔ (Table 7). So ¬p ∧ q means (¬p) ∧ q and p ∨ q ∧ r means p ∨ (q ∧ r). When in doubt, use brackets.

Related conditionals

For p → q: the converse is q → p, the inverse is ¬p → ¬q, and the contrapositive is ¬q → ¬p. A conditional is equivalent to its contrapositive; the converse is equivalent to the inverse; the converse is not equivalent to the original.

Example 17: “The home team wins whenever it is raining” means “If it is raining, then the home team wins.” Contrapositive: “If the home team does not win, then it is not raining.” Converse: “If the home team wins, then it is raining.” Inverse: “If it is not raining, then the home team does not win.”

Definitions 7–8

A tautology is true in every row (p ∨ ¬p); a contradiction is false in every row (p ∧ ¬p). Substituting any propositions for the variables of a tautology gives a tautology (Theorem 1). P ≡ Q (logically equivalent) means identical truth tables, or equivalently that P ↔ Q is a tautology.

Key equivalences
p → q ≡ ¬p ∨ q¬(p → q) ≡ p ∧ ¬q
p → q ≡ ¬q → ¬pp ∨ q ≡ ¬p → q
p ⊕ q ≡ (p ∧ ¬q) ∨ (¬p ∧ q)p ∧ q ≡ ¬(p → ¬q)
p ↔ q ≡ (p ∧ q) ∨ (¬p ∧ ¬q)p ↔ q ≡ ¬p ↔ ¬q
¬(p ↔ q) ≡ p ↔ ¬q ≡ ¬p ↔ q(p → q) ∧ (p → r) ≡ p → (q ∧ r)
(p → r) ∧ (q → r) ≡ (p ∨ q) → r(p → q) ∨ (p → r) ≡ p → (q ∨ r)
(p → r) ∨ (q → r) ≡ (p ∧ q) → r

So every connective can be written with ¬, ∧, ∨ alone: this set is functionally complete (Theorem 2). The laws of the algebra of propositions are the “Propositions” column of the laws table.

Example 20

Show ¬(p ∨ (¬p ∧ q)) ≡ ¬p ∧ ¬q with laws, one step at a time.

  1. ¬(p ∨ (¬p ∧ q)) ≡ ¬p ∧ ¬(¬p ∧ q)De Morgan
  2. ≡ ¬p ∧ (p ∨ ¬q)De Morgan, double negation
  3. ≡ (¬p ∧ p) ∨ (¬p ∧ ¬q)distributive
  4. ≡ F ∨ (¬p ∧ ¬q) ≡ ¬p ∧ ¬qcomplement, identity
Example 21

(p ∧ q) → (p ∨ q) ≡ ¬(p ∧ q) ∨ (p ∨ q) ≡ (¬p ∨ ¬q) ∨ (p ∨ q) ≡ (¬p ∨ p) ∨ (¬q ∨ q) ≡ T, so it is a tautology.

Negating English
  1. Name the simple statements, for example p = “Farid has a cellphone”, q = “Farid has a laptop”.
  2. Write the statement as a formula: p ∧ q.
  3. Negate with De Morgan and ¬(p → q) ≡ p ∧ ¬q: ¬p ∨ ¬q.
  4. Translate back: “Farid does not have a cellphone or he does not have a laptop.” (Example 18)

For a conditional: the negation of “If she works, she will earn money” is “She works and she will not earn money” (Exercise 1.8).

Watch out

The negation of “all the students completed their homework” is “some student did not complete their homework”, not “no student completed it”. You need this for HW1 Task 3.

2.4Predicates and quantifiers

Definitions 13–14

A predicate (propositional function) P(x) on a domain A turns into a proposition for each a ∈ A; formally P: A → {0, 1}. With P(x) = “x < 10”, P(5) is true and P(12) false. Predicates can have several variables: Q(x, y) = “x + y = 5”.

The truth set is TP = {x ∈ A | P(x) is true}. Logic meets sets: T¬P = (TP)′, TP∧Q = TP ∩ TQ, TP∨Q = TP ∪ TQ.

StatementTrue whenFalse when
∀x P(x)P(x) holds for every x (TP = A)there is a counterexample: some x with P(x) false
∃x P(x)P(x) holds for at least one x (TP ≠ ∅)P(x) is false for every x
∃!x P(x)exactly one x makes P(x) trueno x does, or at least two do
Watch out

The domain must be stated, and it changes the answer. ∀x (x² ≥ x) is false over ℝ (x = 1/2) but true over ℤ. Over ℕ: ∀n (n + 4 > 3) is true, ∀n (n + 2 > 8) is false (n = 5), ∃n (n + 5 < 10) is true, and ∃n (n + 10 < 5) is false.

Rules 1–2

If the domain is {x₁, …, xₙ}, then ∀x P(x) ≡ P(x₁) ∧ … ∧ P(xₙ) and ∃x P(x) ≡ P(x₁) ∨ … ∨ P(xₙ).

Restrictions remove terms. With domain {0, 1, 2, 3, 4}: ∀x((x ≠ 3) → P(x)) ≡ P(0) ∧ P(1) ∧ P(2) ∧ P(4), because the x = 3 term is F → P(3), which is true. Likewise ∃x((x ≥ 2) ∧ P(x)) ≡ P(2) ∨ P(3) ∨ P(4).

Uniqueness on a two-element domain {a, b}: ∃!x P(x) ≡ (P(a) ∧ ¬P(b)) ∨ (¬P(a) ∧ P(b)). On a bigger domain, write one conjunction for each element that could be “the one”.

Precedence

∀ and ∃ bind more tightly than every connective: ∀x P(x) ∨ Q(x) means (∀x P(x)) ∨ Q(x).

Theorems 7–8

De Morgan for quantifiers: ¬∀x P(x) ≡ ∃x ¬P(x) and ¬∃x P(x) ≡ ∀x ¬P(x). “Not everyone passed” means “someone failed”. Moving ¬ past a quantifier flips it. Example 34: ¬∀x(P(x) → Q(x)) ≡ ∃x ¬(P(x) → Q(x)) ≡ ∃x(P(x) ∧ ¬Q(x)).

Theorem 6

∀x(P(x) ∧ Q(x)) ≡ ∀x P(x) ∧ ∀x Q(x) and ∃x(P(x) ∨ Q(x)) ≡ ∃x P(x) ∨ ∃x Q(x). The other two do not hold: over ℤ with P = “even” and Q = “odd”, ∀x(P(x) ∨ Q(x)) is true but ∀x P(x) ∨ ∀x Q(x) is false, and ∃x P(x) ∧ ∃x Q(x) is true but ∃x(P(x) ∧ Q(x)) is false.

Example 39

Lewis Carroll's argument, with P(x) = “x is a lion”, Q(x) = “x drinks coffee”, R(x) = “x is fierce” (labels as defined in the notes; see errata): “All lions are fierce” is ∀x(P(x) → R(x)); “Some lions do not drink coffee” is ∃x(P(x) ∧ ¬Q(x)); “Some fierce creatures do not drink coffee” is ∃x(R(x) ∧ ¬Q(x)).

Examples 41–42

Domain {1, …, 9}, P(x, y) = “x + y = 10”: ∀x∃y P(x, y) is true (take y = 10 − x), but ∃y∀x P(x, y) is false (no single y works for every x). Same-type quantifiers commute; mixed ones usually do not.

Domain {1, 2, 3}: ∃x∀y(x² < y + 1) is true (x = 1); ∀x∃y(x² + y² < 12) is true (y = 1); ∀x∀y(x² + y² < 12) is false (x = 2, y = 3).

Negation rule

Pass ¬ from left to right, flipping every quantifier, and negate the predicate: ¬∀x∃y∃z P(x, y, z) ≡ ∃x∀y∀z ¬P(x, y, z).

Free variables

With a quantifier for only some variables, the result is still a predicate. For A = {1, …, 10}, (∀y ∈ A)(x + y < 14) is a predicate in x with truth set {1, 2, 3} (Exercise 1.15).

Quick check

  1. “x + 2 = 5” is a proposition.It is an open sentence: its truth depends on x.
  2. If p is false, then p → q is true.The only false row of → is T → F.
  3. The converse of p → q is equivalent to p → q.The contrapositive is; the converse is not.
  4. ¬(p ∧ q) ≡ ¬p ∧ ¬qDe Morgan gives ¬p ∨ ¬q.
  5. “p only if q” means q → p.It means p → q.
  6. p ⊕ q ≡ ¬(p ↔ q)Exclusive or is true exactly when the two values differ.
  7. ¬∀x P(x) ≡ ∃x ¬P(x)De Morgan for quantifiers.
  8. ∃x(P(x) ∧ Q(x)) ≡ ∃x P(x) ∧ ∃x Q(x)∃ does not distribute over ∧; try even/odd over ℤ.
  9. Over ℤ, ∀x∃y(x + y = 0) is true.Take y = −x.
  10. Over ℤ, ∃y∀x(x + y = 0) is true.One fixed y cannot cancel every x.

P2.2

Tautology, contradiction or neither?

Build a truth table for each, then classify it.

((p → q) ∧ (q → r)) → (p → r)

  • tautology
  • contradiction
  • neither

All 8 rows are T. This is the chain rule (hypothetical syllogism).

(p ∧ q) → p

  • tautology
  • contradiction
  • neither

If p ∧ q is true then p is true, so no row is T → F.

p → (p ∧ q)

  • tautology
  • contradiction
  • neither

False when p = T, q = F; true otherwise.

(p ∨ q) ∧ ¬p ∧ ¬q

  • tautology
  • contradiction
  • neither

¬p ∧ ¬q ≡ ¬(p ∨ q), so this is X ∧ ¬X.

P2.3

Prove with the laws

Name the law used at each step.

  1. (p ∧ q) ∨ (p ∧ ¬q) ≡ p
  2. p → (q → r) ≡ (p ∧ q) → r
  3. p ∨ (p ∧ q) ≡ p (absorption, from the other laws)
  4. ¬(p ↔ q) ≡ p ⊕ q (a truth table is fine)

Hint

For (b), replace each → using a → b ≡ ¬a ∨ b. For (c), write p as p ∧ T first.

Solution
  1. (p ∧ q) ∨ (p ∧ ¬q) ≡ p ∧ (q ∨ ¬q)distributive
  2. ≡ p ∧ T ≡ pcomplement, identity
  1. p → (q → r) ≡ ¬p ∨ (¬q ∨ r)a → b ≡ ¬a ∨ b twice
  2. ≡ (¬p ∨ ¬q) ∨ rassociative
  3. ≡ ¬(p ∧ q) ∨ r ≡ (p ∧ q) → rDe Morgan, then a → b again
  1. p ∨ (p ∧ q) ≡ (p ∧ T) ∨ (p ∧ q)identity

(d) Both sides have the column F, T, T, F (rows TT, TF, FT, FF): each is true exactly when p and q differ.

P2.4

Converse, inverse, contrapositive

For “If a number is divisible by 6, then it is divisible by 3”, write the converse, the inverse and the contrapositive, and say which are true.

Answer

Converse: If a number is divisible by 3, then it is divisible by 6. False (9).

Inverse: If a number is not divisible by 6, then it is not divisible by 3. False (9 again).

Contrapositive: If a number is not divisible by 3, then it is not divisible by 6. True, since it is equivalent to the original.

Rewrite as “if … then”

  2. A sufficient condition for passing is scoring at least 60.
  3. The alarm sounds unless the code is entered.
  4. A working battery is necessary for the phone to turn on.

P2.6

Negate in English

Same format as HW1 Task 3: name the propositions, write the formula, negate it, and translate back.

  1. If it rains, then the match is cancelled.
  2. All the lights are off and the door is locked.
  3. Some windows are open or the alarm is off.
Hint

Make the “all” statement a single proposition, for example w = “all the windows are closed”. Then “some window is open” is ¬w.

Solution

(a) r = “it rains”, c = “the match is cancelled”. Statement r → c; negation r ∧ ¬c: “It rains and the match is not cancelled.”

(b) ℓ = “all the lights are off”, d = “the door is locked”. Statement ℓ ∧ d; negation ¬ℓ ∨ ¬d: “Some light is on or the door is unlocked.”

(c) w = “all the windows are closed”, a = “the alarm is on”. Statement ¬w ∨ ¬a; negation w ∧ a: “All the windows are closed and the alarm is on.”

P3.6

Counting with connectives

Answer
