Lecture 1

Sets and functions

Every other structure in the course is built on sets. This chapter covers how to describe sets, how functions connect them, the set operations and their laws, and (Part 4) how to compare the sizes of infinite sets.

1.1Sets and how to describe them

Definition

A set is an unordered collection of objects, its elements. Write a ∈ A when a is an element of A, and a ∉ A when it is not.

Two ways
Listing
A = {2, 3, −1, 0, 15}
Set-builder
B = {x | x is an odd integer, x > 0} = {1, 3, 5, …}. Read the bar as “such that” and the comma as “and”.
Key fact

Order and repetition never matter: {x | x² − 3x + 2 = 0} = {2, 1} = {1, 2, 2, 1} (Example 1).

Number sets

ℕ = ℤ⁺ = {1, 2, 3, …} (in this course ℕ starts at 1), ℤ the integers, ℚ the rationals, ℝ the reals, ℂ the complex numbers, and ℤ⁺ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ.

  • ℚ is the set of fractions p/q with p ∈ ℤ, q ∈ ℕ; as decimals, exactly the finite or repeating ones.
  • The irrational numbers ℝ ∖ ℚ (for example √2, √3) are the non-repeating decimals.
  • ℂ is the set of pairs (a, b) with (a, b) + (c, d) = (a + c, b + d) and (a, b)(c, d) = (ac − bd, ad + bc). A real number a is the pair (a, 0).
Example

Write 0.6(7) = 0.6777… as a fraction.

0.6777… = 6/10 + (7/100 + 7/1000 + …). The bracket is a geometric series with first term a₁ = 7/100 and ratio r = 1/10, so it sums to a₁/(1 − r) = (7/100)/(9/10) = 7/90. Total: 54/90 + 7/90 = 61/90.

Definition

Subset: A ⊆ B when every element of A is in B. If some element of A is not in B, write A ⊈ B.

Equality: A = B exactly when A ⊆ B and B ⊆ A. This is the standard way to prove two sets are equal.

Proper subset: A ⊂ B means A ⊆ B and A ≠ B.

Theorems 1–2

A ⊆ A; if A ⊆ B and B ⊆ A then A = B; if A ⊆ B and B ⊆ C then A ⊆ C. For every set, ∅ ⊆ A ⊆ U, where U is the universal set and ∅ the (only) empty set.

Watch out

∅ and {∅} are different. ∅ has no elements; {∅} is a singleton whose one element is ∅. Think of an empty folder versus a folder that holds one empty folder. So ∅ ∈ {∅} and ∅ ⊆ {∅} are both true, while {∅} ⊆ ∅ is false.

More terms
Disjoint
no common elements; {1, 2} and {4, 5, 6} are disjoint.
Class of sets
a set whose elements are sets (also called a collection or family); a subclass is a subset of it.
Finite / infinite
finite sets have a definite number of elements; removing 1, 2, 3, … elements from an infinite set always leaves elements.
Power set
P(S), the class of all subsets of S, including ∅ and S.
Statement 1

If S has n elements, then P(S) has 2ⁿ elements: each element of S is either in a subset or out of it. That is why P(S) is also written 2S.

1.2Functions

Definition 2

A function f: X → Y assigns to every x ∈ X exactly one f(x) ∈ Y. X is the domain and Y the codomain. The image (range) is f(X) = {f(x) | x ∈ X}. For y ∈ Y the preimage is f⁻¹(y) = {x ∈ X | f(x) = y}; it is empty exactly when y ∉ f(X).

TypeDefinitionEach preimage f⁻¹(y) has
Injective (one-to-one)x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂), equivalently f(x₁) = f(x₂) ⇒ x₁ = x₂at most one element
Surjective (onto)f(X) = Yat least one element
Bijectiveinjective and surjective (a one-to-one correspondence)exactly one element
How to prove
  • Injective: assume f(x₁) = f(x₂) and derive x₁ = x₂. To disprove, find x₁ ≠ x₂ with the same image.
  • Surjective: take any y ∈ Y and find an x with f(x) = y. To disprove, find a y that nothing maps to.
Examples 4–6
  • tan: (−π/2, π/2) → ℝ is a bijection: every horizontal line meets the graph exactly once.
  • sin: ℝ → ℝ is neither: sin 0 = sin π, and nothing maps to 2.
  • sin: ℝ → [−1, 1] is onto. Whether a function is onto depends on the codomain.
Composition

For f: X → Y and g: Y → Z, (g∘f)(x) = g(f(x)). The identity is idX(x) = x. A function is a bijection exactly when it has an inverse g: Y → X with g∘f = idX and f∘g = idY. An injective f has an inverse f⁻¹: f(X) → X defined on its image.

Products

The Cartesian product is X₁ × … × Xₙ = {(x₁, …, xₙ) | xᵢ ∈ Xᵢ}. Example: {1, 2, 3} × {a, b} = {(1, a), (1, b), (2, a), (2, b), (3, a), (3, b)}, and [0, 1] × [0, 1] is the unit square.

A relation from X to Y is any subset of X × Y. A function is a relation in which every x appears in exactly one pair (x, y); that set of pairs is its graph. A function X × … × X → X with n factors is an n-ary operation on X (unary, binary, ternary for n = 1, 2, 3).

Example 8

Division with remainder. For a ∈ ℤ and m ∈ ℕ there are unique q, r with a = qm + r and 0 ≤ r < m. So 13 = 4·3 + 1 and −13 = (−5)·3 + 2: the remainder is never negative.

s ≡ t (mod m) means m divides s − t. All integers are congruent mod 1; mod 2 the two classes are the even and the odd numbers.

Example 12

Floor and ceiling. ⌊x⌋ is the greatest integer ≤ x, ⌈x⌉ the least integer ≥ x, and x − ⌊x⌋ the fractional part. ⌊3.14⌋ = 3, ⌊−3.14⌋ = −4, ⌈−3.14⌉ = −3, ⌊√5⌋ = 2; the fractional part of −3.14 is −3.14 − (−4) = 0.86. If x is not an integer, ⌈x⌉ = ⌊x⌋ + 1.

1.3Set operations and Venn diagrams

Definitions

A ∪ B = {x | x ∈ A or x ∈ B}, A ∩ B = {x | x ∈ A and x ∈ B}, A′ = {x ∈ U | x ∉ A}, B ∖ A = {x | x ∈ B, x ∉ A}, and the symmetric difference A ⊕ B = (A ∖ B) ∪ (B ∖ A) = (A ∪ B) ∖ (A ∩ B) (“union mod 2”). A and B are disjoint when A ∩ B = ∅; then A ∪ B is a disjoint union.

Theorems 3–4

A ∩ B ⊆ A ⊆ A ∪ B. The following are equivalent: A ⊆ B; A ∩ B = A; A ∪ B = B.

Generalized

⋃ᵢ Aᵢ = {x | x ∈ Aᵢ for some i} and ⋂ᵢ Aᵢ = {x | x ∈ Aᵢ for every i}.

Example (Exercise 1.6): let Aₙ = {n, 2n, 3n, …}. Then A₃ ∩ A₅ = A₁₅ and A₄ ∩ A₆ = A₁₂ (multiples of the least common multiple), and ⋃p prime Ap = ℕ ∖ {1}, because every integer from 2 on has a prime factor. If one set in an intersection is empty, the whole intersection is empty.

Theorem 5

Fundamental products. For sets A₁, …, Aₙ, a fundamental product is A₁* ∩ … ∩ Aₙ* where each Aᵢ* is Aᵢ or Aᵢ′. There are 2ⁿ of them, any two are disjoint, and their union is U. For three sets these are the 8 regions of a three-circle Venn diagram; in Lecture 4–5 they return as minterms.

Partitions

A partition of S splits it into nonempty, pairwise disjoint cells whose union is S. With S = {a, b, c, d, e, f, g} (Exercise 1.8): [{a, c, e}, {b}, {d, g}] is not a partition (f is missing), [{a, e, g}, {c, d}, {b, e, f}] is not one (e is in two cells), and [{a, b, e, g}, {c}, {d, f}] is. Any function f: A → B partitions A into the preimages of its values (Example 10).

Example 9

Arguments with Venn diagrams. All my friends are musicians. Akif is my friend. None of my neighbours are musicians. Therefore Akif is not my neighbour. Draw the friends inside the musicians and the neighbours outside the musicians; Akif lies in the friends region, which cannot meet the neighbours. The argument is valid.

1.4Algebra of sets, duality, images

Definition 5

The algebra of sets is a family of subsets of U containing ∅ and U, with the binary operations ∪, ∩ and the unary complement ′. Its laws are the “Sets” column of the laws table (Table 1 in the notes).

Two proof methods

1. Element chasing. Show that x ∈ LHS implies x ∈ RHS, and the converse. De Morgan (10a):

x ∈ (A ∪ B)′ ⟺ x ∉ A ∪ B ⟺ x ∉ A and x ∉ B ⟺ x ∈ A′ and x ∈ B′ ⟺ x ∈ A′ ∩ B′.

2. Algebra. Rewrite with the laws, using X ∖ Y = X ∩ Y′ (Exercise 1.4). Exercise 1.5:

  1. (A ∪ B) ∖ (A ∩ B) = (A ∪ B) ∩ (A ∩ B)′difference
  2. = (A ∪ B) ∩ (A′ ∪ B′)De Morgan
  3. = (A ∩ A′) ∪ (A ∩ B′) ∪ (B ∩ A′) ∪ (B ∩ B′)distributive
  4. = ∅ ∪ (A ∩ B′) ∪ (B ∩ A′) ∪ ∅ = (A ∖ B) ∪ (B ∖ A)complement, identity
Duality

The dual of a set equation swaps ∪ ↔ ∩ and U ↔ ∅. The dual of (U ∩ A) ∪ (B ∩ A) = A is (∅ ∪ A) ∩ (B ∪ A) = A. If an equation is an identity, so is its dual.

Theorems 7–9

For f: X → Y: f⁻¹(A ∪ B) = f⁻¹(A) ∪ f⁻¹(B), f⁻¹(A ∩ B) = f⁻¹(A) ∩ f⁻¹(B), f(A ∪ B) = f(A) ∪ f(B). Prove each by showing LHS ⊆ RHS and RHS ⊆ LHS. Preimages also respect complements: f⁻¹(Y ∖ B) = X ∖ f⁻¹(B) (Exercise 2.8).

Watch out

Images do not respect intersections; only f(A ∩ B) ⊆ f(A) ∩ f(B) holds. The projection (x, y) ↦ (x, 0) sends the disjoint segments {0 ≤ x ≤ 1, y = 0} and {0 ≤ x ≤ 1, y = 1} onto the same segment (Remark 1).

1.5Comparing infinite sets

Part 4 of Lecture 1: optional reading, mandatory for math students. HW1 Task 2 uses it.

Definition 3

X and Y are equivalent, X ~ Y, when there is a bijection X → Y. This relation is reflexive (use id), symmetric (use the inverse) and transitive (compose). Finite sets are equivalent exactly when they have the same number of elements; for infinite sets, counting fails but bijections still work.

Definition 6

A set is countable if it is equivalent to ℤ⁺, that is, its elements can be listed a₁, a₂, a₃, … An infinite set that is not countable is uncountable. All countable sets are equivalent to each other.

Examples 14–17
  • ℤ is countable: list 0, −1, 1, −2, 2, …, that is n ↦ 2n + 1 for n ≥ 0 and n ↦ 2|n| for n < 0.
  • The positive even numbers (n ↦ 2n) and the powers of 2 (n ↦ 2ⁿ) are countable.
  • ℚ is countable: write r = p/q in lowest terms with q > 0 and call |p| + q its height. Each height has finitely many rationals (height 3: −2/1, −1/2, 1/2, 2/1), so list height 1, then height 2, and so on.

These show something impossible for finite sets: an infinite set can be equivalent to a proper subset of itself.

Theorems 10–13
  1. Every subset of a countable set is finite or countable.
  2. A finite or countable union of countable sets is countable: write the sets as rows and count along the diagonals.
  3. Every infinite set M has a countable subset: pick a₁ ∈ M, then a₂ ≠ a₁, then a₃ ∉ {a₁, a₂}, and so on.
  4. Every infinite set is equivalent to one of its proper subsets: take a countable {a₁, a₂, …} ⊆ M, send aₙ ↦ a₂ₙ₋₁, and fix every other element. Then M ~ M ∖ {a₂, a₄, …}.

Cardinality

|M| = |N| means M ~ N. Countable sets have cardinality ℵ₀ (aleph-null); [0, 1], every interval, ℝ and the plane have the cardinality of the continuum, c. |A| ≤ |B| means there is an injection A → B, and |A| < |B| means there is an injection but no bijection. So ℵ₀ < c.

  • Cantor–Bernstein (Theorem 16): if |A| ≤ |B| and |B| ≤ |A|, then |A| = |B|.
  • Cantor (Theorem 15): |P(M)| > |M| for every set M, so there is no largest cardinality. For any f: M → P(M), the set X = {a ∈ M | a ∉ f(a)} is not f(x) for any x.
  • Continuum hypothesis: no cardinality lies strictly between ℵ₀ and c. Paul Cohen showed in 1963 that the usual axioms cannot decide it.

P1.4

Operations on a small universe

Let U = {1, 2, …, 10}, A = {1, 2, 3, 4, 5, 6}, B = {4, 5, 6, 7, 8}, C = {2, 4, 6, 8, 10}. Find:

  1. A ∩ B and A ∪ B
  2. A′ and B′ ∩ C
  3. A ∖ B, B ∖ A and A ⊕ B
  4. (A ∪ C)′
  5. A ∩ (B ⊕ C)
Hint

Complements are taken inside U. For (e), first compute B ⊕ C = (B ∖ C) ∪ (C ∖ B).

(e) B ⊕ C = {5, 7} ∪ {2, 10} = {2, 5, 7, 10}, so A ∩ (B ⊕ C) = {2, 5}.

P1.6

An element-chasing proof

Prove that A is the disjoint union of A ∖ B and A ∩ B (Exercise 2.3(a) of Lecture 1).

Hint

There are three things to show: the two parts are disjoint, their union is inside A, and A is inside their union.

Solution
  1. Disjoint: if x ∈ A ∖ B then x ∉ B, so x ∉ A ∩ B.
  2. Union ⊆ A: both A ∖ B and A ∩ B are subsets of A.
  3. A ⊆ union: take x ∈ A. If x ∈ B, then x ∈ A ∩ B; if x ∉ B, then x ∈ A ∖ B.
P1.7

Unions and intersections of families

  1. Bₙ = [0, 1/n] for n ∈ ℕ: find ⋃ Bₙ and ⋂ Bₙ.
  2. Cₙ = (0, 1/n): find ⋂ Cₙ.
  3. Dₙ = {k ∈ ℤ | −n ≤ k ≤ n} for n ≥ 1: find ⋃ Dₙ and ⋂ Dₙ.
  4. With Aₙ = the multiples of n: find A₆ ∩ A₉ and A₂ ∪ A₄.
Hint

For a decreasing family (each set inside the previous one), the union is the first set. For the intersection, ask which points survive every n.

Answer

(a) ⋃ Bₙ = B₁ = [0, 1]; ⋂ Bₙ = {0}, since 0 is in every Bₙ and any x > 0 drops out once 1/n < x.

(b) ⋂ Cₙ = ∅: 0 is never included, and every x > 0 drops out eventually.

(c) ⋃ Dₙ = ℤ and ⋂ Dₙ = D₁ = {−1, 0, 1}.

(d) A₆ ∩ A₉ = A₁₈ (least common multiple), and A₂ ∪ A₄ = A₂ because A₄ ⊆ A₂.

Injective, surjective, bijective?

Show that [0, 1] ~ [0, 1). This is the warm-up for HW1 Task 2.

Hint

[0, 1] has one extra point, 1. Find a sequence inside [0, 1] that starts at 1, and shift it one place along.

Solution

Use the countable subset {1, 1/2, 1/3, …}. Define f(1/n) = 1/(n + 1) for n ≥ 1 and f(x) = x for every other x.

So 1 ↦ 1/2, 1/2 ↦ 1/3, … The map is injective (the shift is injective and does not meet the fixed points), and its image is [0, 1): 1 is no longer hit, every 1/(n + 1) is, and every other point is fixed. So f: [0, 1] → [0, 1) is a bijection. This shift along a countable sequence is the idea of Theorem 13.

P1.15

Valid or not? (Venn diagrams)

Decide with a Venn diagram whether the conclusion follows.

  1. All squares are rectangles. No rectangle is a circle. So no square is a circle.Squares lie inside rectangles, which do not meet circles.
  2. All cats are mammals. Some mammals are pets. So some cats are pets.Draw the pets meeting the mammals only outside the cats. The premises hold and the conclusion fails.
