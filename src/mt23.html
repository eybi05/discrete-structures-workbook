Task 1

Minimal AND–OR circuit · 4 pt

Design a three-input minimal AND–OR circuit L with truth table T[x, y, z; L] = [00001111, 00110011, 01010101; 11011001].

Solution

Step 1: positions 1, 2, 4, 5, 8 give L = x′y′z′ + x′y′z + x′yz + xy′z′ + xyz.

Steps 2–3: yz and y′z′ are essential; x′y′z goes with x′y′ or x′z:

L = yz + y′z′ + x′y′ or L = yz + y′z′ + x′z

Task 2

Truth table of an expression · 5 pt

Find T(E) for E = (xy′ + z′)′(x + yz′) + (x′z + y)′(y′z) + x′z + xy′z′. Step 1: an SoP form (3 pt). Step 2: the CSoP form (1 pt). Step 3: T(E) (1 pt).

Hint

Almost the Fall 2025 expression, but here the second factor is (x′z + y)′, not (x′z + y). (xy′ + z′)′ = (x′ + y)z and (x′z + y)′ = (x + z′)y′.

Solution

(x′ + y)z(x + yz′) = x′zx + x′zyz′ + xyz + yzyz′ = xyz

(x + z′)y′ · y′z = xy′z + z′y′z = xy′z

So E = xyz + xy′z + x′z + xy′z′. CSoP: xyz + xy′z + x′yz + x′y′z + xy′z′, positions 8, 6, 4, 2, 5, so T(E) = 01011101.

Not asked, but xyz + xy′z + x′z = z, so E = z + xy′.

Task 3

MSoP from a truth table · 4 pt

Find E(x, y, z) in MSoP form with T(E) = 11011001.

Solution

The truth table of Task 1 again: E = yz + y′z′ + x′y′ or E = yz + y′z′ + x′z.

Task 4

Two 4-variable maps · 6 pt

Find an MSoP for each map. These are the same two maps as Fall 2025, Variant 1, Task 4:

(A) xyz′t′, xyz′t, xy′zt, xy′zt′, xy′z′t′, x′y′zt′, x′yzt, x′yz′t′, x′yz′t

(B) xyzt, xyz′t′, xyz′t, the whole row xy′, x′y′z′t′, x′yzt, x′yz′t′, x′yz′t

Answer

(A) Two minimal sums, 5 products and 14 literals each:

yz′ + x′yt + xy′z + y′zt′ + xz′t′
yz′ + x′yt + xy′z + y′zt′ + xy′t′

(B) One minimal sum: E = yt + xy′ + z′t′.

Task 5

Prim's algorithm · 4 pt

Use Prim's algorithm to find a minimum spanning tree in the graph. Press the edges in the order Prim's algorithm adds them; each choice is checked.

Hint

Start with any edge of weight 1. At every step, list the edges with exactly one end in the tree and take a lightest one. 12 vertices means 11 edges.

Solution

The sheet's order, starting from {e, f}:

ChoiceEdgeWeight
1{e, f}1
2{e, i}1
3{i, j}2
4{f, b}2
5{b, a}2
6{f, g}3
7{g, k}1
8{k, m}1
9{g, h}2
10{h, d}1
11{d, c}2

Total weight 18. At step 6 the tree is {a, b, e, f, i, j} and both {f, g} and {j, k} leave it with weight 3. Either choice gives a minimum spanning tree of weight 18.

Task 6

Quantifiers · 2 pt

6.1 The negation of ∃x ∀y ∀z P(x, y, z) is

  • ∀x ∀y ∀z ¬P(x, y, z)
  • ∀x ∃y ∃z ¬P(x, y, z)
  • ∃x ∃y ∃z ¬P(x, y, z)
  • ∀x ∃y ∀z ¬P(x, y, z)

¬∃x ∀y ∀z P = ∀x ¬∀y ∀z P = ∀x ∃y ¬∀z P = ∀x ∃y ∃z ¬P.

6.2 Over the integers, what are the truth values?

  1. ∀x(x < 1)x = 1 is a counterexample.
  2. ∃!x(x⁵ = −1)Only x = −1.
  3. ∃!x(2x + 3 = 1)Only x = −1.
  4. ∃x(x = 4x + 1)x = −1/3 is not an integer.
Task 7

Polynomials with rational coefficients · 2 pt

Using “a finite or countable union of countable sets is countable”, prove that the set of all polynomials with rational coefficients is countable.

Hint

Split the set by degree, and show each piece is countable by induction on the degree.

Model proof

This is the same task as Fall 2025, Variant 1, Task 7; the model proof is there. In short: let Bₙ be the polynomials of degree at most n. B₀ = ℚ is countable, and Bₙ = ⋃a∈ℚ {a xⁿ + q : q ∈ Bₙ₋₁} is a countable union of countable sets. So every Bₙ is countable, and the set of all polynomials, ⋃ₙ Bₙ, is countable too. ∎
