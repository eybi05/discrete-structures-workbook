Lectures 8–9

Counting

Lectures 8–9 count the elements of finite sets without listing them. Two rules do almost all the work: add when the cases are disjoint, multiply when the choices are made one after another. Inclusion–exclusion repairs the sum rule when the cases overlap, the pigeonhole principle proves that something must happen, and permutations and combinations package the product rule for “order matters” and “order does not matter”.

5.1The sum and product rules

Lemmas 1–2

If A and B are finite and disjoint, then n(A ∪ B) = n(A) + n(B). For any finite A, B: n(A × B) = n(A)·n(B).

Consequences: n(A ∖ B) = n(A) − n(A ∩ B) (Corollary 1) and n(A′) = n(U) − n(A) (Corollary 2). Both extend to any finite number of sets.

The two rules in words

Sum rule. A task can be done in one of m ways or in one of n other ways, with no way counted in both lists: there are m + n ways.

Product rule. A procedure is a first task and then a second task, with m ways for the first and, for each of them, n ways for the second: there are mn ways.

Signal words: “one of” or “either … or” → add; “one of each”, “and then”, “a string of” → multiply.

Example 2: sections

5 Calculus 1, 3 Discrete Structures and 4 Linear Algebra sections. One of each kind: 5·3·4 = 60. Just one section: 5 + 3 + 4 = 12.

Exercises 1.4–1.5: loops

m nested loops of lengths n₁, …, nₘ run the innermost statement n₁n₂⋯nₘ times (product rule). The same loops written one after another run n₁ + n₂ + ⋯ + nₘ times (sum rule).

5.2Inclusion–exclusion

Theorems 1–3 (IEP)

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(A ∩ C) − n(B ∩ C) + n(A ∩ B ∩ C)

In general, with sₖ the sum of the sizes of all k-fold intersections: n(A₁ ∪ ⋯ ∪ Aᵣ) = s₁ − s₂ + s₃ − ⋯ + (−1)ʳ⁻¹sᵣ.

Alternate form (by De Morgan): the number of elements in none of the sets is n(A₁′ ∩ ⋯ ∩ Aᵣ′) = |U| − s₁ + s₂ − ⋯ + (−1)ʳsᵣ = |U| − n(A₁ ∪ ⋯ ∪ Aᵣ).

5.3The pigeonhole principle

PP and GPP

PP. If k + 1 or more objects are placed in k boxes, some box contains at least two of them. Equivalently (Corollary 3): a function from a set of k + 1 or more elements to a set of k elements is not one-to-one.

GPP. If N objects are placed in k boxes, some box contains at least ⌈N/k⌉ of them. Here ⌈x⌉ rounds up: ⌈3.2⌉ = 4, ⌈−3.2⌉ = −3, ⌈3⌉ = 3.

Both are proved by contradiction: if every box had at most ⌈N/k⌉ − 1 objects, there would be at most k(⌈N/k⌉ − 1) < k(N/k + 1 − 1) = N objects.

“How many to guarantee r in one box?”

The answer is N = k(r − 1) + 1. It is enough, because ⌈N/k⌉ ≥ r. It is the least, because k(r − 1) objects fit with exactly r − 1 in every box. Always give both halves when you justify a minimum.

Example 9: to be sure six students share one of five grades, 5·5 + 1 = 26 students are needed. With 25, five could get each grade.

Example 7: a multiple made of 0s and 1s

Take the n + 1 numbers 1, 11, 111, … (the last has n + 1 ones). There are only n remainders mod n, so two of them, a > b, have the same remainder. Then n | a − b, and a − b = 11…100…0 has only 0s and 1s.

Example 11: exactly 19 games

In 40 days a team plays at least one game a day and at most 60 games. Let aⱼ be the number of games in the first j days: 1 ≤ a₁ < ⋯ < a₄₀ ≤ 60, so 20 ≤ a₁ + 19 < ⋯ < a₄₀ + 19 ≤ 79. These 80 numbers all lie in {1, …, 79}, so two are equal; each list has distinct entries, so aᵢ = aⱼ + 19 for some j < i, and exactly 19 games were played on days j + 1, …, i.

Example 12: one divides another

Among any n + 1 integers in {1, …, 2n}, one divides another. Write each as aⱼ = 2kⱼ·qⱼ with qⱼ odd. There are only n odd numbers below 2n, so qᵢ = qⱼ for some i ≠ j, and the one with the smaller power of 2 divides the other.

5.4Factorials and binomial coefficients

Definitions 1–2

n! = n(n − 1)⋯2·1, with 0! = 1 and n! = n·(n − 1)!.

C(n, r) = n(n − 1)⋯(n − r + 1) / r! = n! / (r!(n − r)!)

The first form has r factors above and below (Corollary 4). Use C(n, r) = C(n, n − r) (Lemma 3) to keep r small: C(10, 7) = C(10, 3) = 10·9·8/(3·2·1) = 120. Also C(n, 0) = C(n, n) = 1.

Theorems 4–5

Pascal's identity. C(n + 1, r) = C(n, r − 1) + C(n, r).

Binomial theorem. (a + b)ⁿ = Σᵣ₌₀ⁿ C(n, r)·aⁿ⁻ʳbʳ, proved by induction on n with Pascal's identity in the step.

With a = b = 1: C(n, 0) + C(n, 1) + ⋯ + C(n, n) = 2ⁿ (Corollary 6). This is a second proof that an n-set has 2ⁿ subsets (Theorem 10): count the subsets of each size k and add.

5.5Permutations and combinations

Theorems 6–9

A permutation of a set is an ordered arrangement of all of it, a bijection X → X: there are P(n) = n!. An r-permutation arranges r of the n objects in order: P(n, r) = n(n − 1)⋯(n − r + 1) = n!/(n − r)!.

With repeated objects (n₁ alike, n₂ alike, …): P(n; n₁, …, nᵣ) = n!/(n₁!n₂!⋯nᵣ!). BENZENE has 3 E's and 2 N's: 7!/(3!2!) = 420.

An r-combination is an r-element subset; order does not count. Each one can be ordered in r! ways, so P(n, r) = r!·C(n, r) and C(n, r) = n!/(r!(n − r)!), the binomial coefficient.

Exercise 1.12: a row and a circle

5 people in a row: 5! = 120. Around a round table only the order relative to one person matters, so fix that person and arrange the other 4: 4! = 24. In general n objects make (n − 1)! circular arrangements.

Exercises 1.16–1.17: committees

13 students, 8 men and 5 women. A 6-member committee: C(13, 6) = 1716. With 3 men and 3 women: C(8, 3)·C(5, 3) = 56·10 = 560. President, vice president and treasurer: P(13, 3) = 13·12·11 = 1716. A committee of 3 with a chairperson from 9 people: 9·C(8, 2) = 252.

“Together” and “not together”

To keep a group together, glue it into one block, arrange the blocks, then arrange inside the block: two people side by side in a row of 5 give 4!·2! = 48. For “not together”, count all and subtract “together”. For “at least one”, subtract “none” from all: C(12, 4) − C(9, 4) = 369 committees with at least one of 3 women.

P10.14

Puzzle: a multiple made of 0s and 1s

Put the steps of Example 7 in order: every positive integer n has a multiple whose decimal digits are all 0 or 1.

  1. Consider the n + 1 integers 1, 11, 111, …, the last with n + 1 ones.
  2. Division by n leaves one of only n remainders 0, 1, …, n − 1.
  3. By the pigeonhole principle two of the integers, a > b, have the same remainder.
  4. Then a = mn + q and b = kn + q, so a − b = (m − k)n is a multiple of n.
  5. Subtracting a shorter string of ones from a longer one leaves ones followed by zeros, so a − b has only the digits 0 and 1. ∎
