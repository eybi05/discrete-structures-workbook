3.3Boolean algebras

Definition 3

A Boolean algebra is a set B with operations + and · (written as juxtaposition), a complement ′, and two distinct elements 0, 1, such that for all a, b, c:

[B1] Commutativea + b = b + aab = ba
[B2] Distributivea + bc = (a + b)(a + c)a(b + c) = ab + ac
[B3] Identitya + 0 = aa · 1 = a
[B4] Complementa + a′ = 1aa′ = 0

Precedence: ′, then ·, then +. So a + bc means a + (bc) and ab′ means a(b′).

Examples
  • Sets ⟨P(U), ∪, ∩, ′, ∅, U⟩, propositions ⟨∨, ∧, ¬, F, T⟩, and circuits.
  • B = {0, 1} with 1 + 1 = 1, 1 · 0 = 0, 0′ = 1.
  • Bⁿ, the n-bit strings with bitwise operations: 110011 + 111000 = 111011, 110011 · 111000 = 110000, (110011)′ = 001100. Bⁿ has 2ⁿ elements.

A subalgebra is a subset closed under +, ·, ′. Two Boolean algebras are isomorphic if a bijection f satisfies f(a + b) = f(a) + f(b), f(ab) = f(a)f(b), f(a′) = f(a)′.

Theorem 4

Duality. The dual of a statement swaps + ↔ · and 0 ↔ 1. The axioms are their own duals, so the dual of every theorem is a theorem. Example 3: the dual of (1 + a)(b + 0) = b is (0 · a) + (b · 1) = b.

Theorem 5

From B1–B4 you can prove: idempotent a + a = a, aa = a; boundedness a + 1 = 1, a · 0 = 0; absorption a + ab = a, a(a + b) = a; associativity; uniqueness of complement (if a + x = 1 and ax = 0 then x = a′); involution (a′)′ = a; 0′ = 1, 1′ = 0; De Morgan (a + b)′ = a′b′, (ab)′ = a′ + b′.

Example (B5b), citing an axiom at every step:

  1. a = a · 1 = a(a + a′)B3, B4
  2. = aa + aa′ = aa + 0 = aaB2, B4, B3

The dual chain proves a + a = a.

Theorem 8

a + b = b ⟺ ab = a ⟺ a′ + b = 1 ⟺ ab′ = 0. For sets, each says A ⊆ B.

Watch out

This is not the algebra of numbers. 1 + 1 = 1; a + bc = (a + b)(a + c) holds; and nothing cancels: a + b = a + c does not give b = c (take a = 1).

Handy identities

a + a′b = a + b, since a + a′b = (a + a′)(a + b) = a + b. Consensus: ab + a′c + bc = ab + a′c. Neither is listed in the notes, but both follow from the laws (see P5.3) and save time.

3.4Sum-of-products forms

Definitions 4–7
Literal
a variable or its complement: x, x′, y, …
Fundamental product
a literal, or a product of literals with no variable repeated: xz′, xy′z, x′yz. Any product of literals reduces to 0 or a fundamental product: xyx′z = 0 since xx′ = 0, and xyzy = xyz since yy = y.
Contained in
P₁ is contained in P₂ when every literal of P₁ is a literal of P₂. Then P₁ + P₂ = P₁ by absorption: x′z + x′yz = x′z.
SoP expression
a fundamental product, or a sum of fundamental products none of which is contained in another (also called DNF).

Example 7: E₁ = xz′ + y′z + xyz′ is not an SoP expression because xz′ is contained in xyz′; absorbing gives xz′ + y′z.

Algorithm 1

Any expression to SoP.

  1. Move complements inward with De Morgan and involution until they sit on single variables.
  2. Multiply out with the distributive law.
  3. Reduce each product to 0 or a fundamental product (commutative, idempotent, complement laws).
  4. Drop the 0s and any product that contains another (absorption).
Example 8

E = ((xy)′z)′ ((x′ + z)(y′ + z′))′

  1. = ((xy)″ + z′)((x′ + z)′ + (y′ + z′)′) = (xy + z′)(xz′ + yz)step 1
  2. = xyxz′ + xyyz + xz′z′ + yzz′step 2
  3. = xyz′ + xyz + xz′ + 0step 3
  4. = xyz + xz′step 4: xz′ absorbs xyz′
Definition 9

A minterm is a fundamental product containing all n variables (there are 2ⁿ). A complete sum-of-products (CSoP, CDNF) is a sum of minterms. Every nonzero expression has exactly one CSoP form (Theorem 9).

Algorithm 2

SoP to CSoP. If a product P misses the variable xᵢ, replace it by P(xᵢ + xᵢ′) and multiply out (allowed because xᵢ + xᵢ′ = 1); delete repeated products. Repeat until every product is a minterm.

Example 9: E = x(y′z)′ = x(y + z′) = xy + xz′ = xy(z + z′) + x(y + y′)z′ = xyz + xyz′ + xyz′ + xy′z′ = xyz + xyz′ + xy′z′.

Definitions 10–11

For an SoP expression, EL counts the literals (with repetition) and ES the products: E = xyz + x′y′t + xy′z′t + x′yzt has EL = 14, ES = 4. E is simpler than an equivalent F when EL < FL and ES ≤ FS, or EL ≤ FL and ES < FS. A minimal SoP (MSoP) has no simpler equivalent; there can be several.

A fundamental product P is a prime implicant of E when P + E = E but no fundamental product contained in P has this property. Theorem 10: a minimal SoP is a sum of prime implicants. Karnaugh maps find them by eye.

3.5Karnaugh maps

Definition 12

Two fundamental products are adjacent when they have the same variables and differ in exactly one literal. Their sum drops that variable: xyz′ + xy′z′ = xz′(y + y′) = xz′. Not adjacent: x′yzt and xyz′t (two literals differ), or xyz′ and xyzt (different variables).

Course layout

Each square is one minterm. Neighbouring labels differ in one literal, so squares that share a side are adjacent products. The 3-variable map is glued left to right (a cylinder); the 4-variable map is also glued top to bottom (a torus), so even the four corners are neighbours.

Definition 14

A basic rectangle is a block of 1, 2, 4 or 8 squares in a 1×1, 1×2, 1×4, 2×2 or 2×4 shape (wrapping across the glued edges is allowed). With 4 variables it gives a product of 4, 3, 2 or 1 literals; with 3 variables, 1, 2 or 4 squares give 3, 2 or 1 literals. The product consists of the literals shared by every square of the rectangle. These three rectangles are from Exercise 1.8:

Procedure
  1. Check the squares of E; expand each product into all of its squares first.
  2. Find the prime implicants: maximal basic rectangles of checked squares, as large as possible, wrapping round the edges.
  3. A checked square that lies in only one prime implicant makes that prime essential: it appears in every minimal sum.
  4. Cover the remaining checks with as few prime implicants as possible, preferring larger ones.
  5. If there is a tie, there are several minimal sums. List all of them.
Example 12

(a) E₁ = xyz + xyz′ + x′yz′ + x′y′z: three prime implicants, all needed.

(b) E₂ = xyz + xyz′ + xy′z + x′yz + x′y′z: the 2×2 block z wraps across the side edges.

(c) E₃ = xyz + xyz′ + x′yz′ + x′y′z′ + x′y′z: four prime implicants, and either yz′ or x′z′ completes the cover, so there are two minimal sums.

Example 14

E = xy′ + xyz + x′y′z′ + x′yzt′. Check the four squares of xy′, two of xyz, two of x′y′z′ and one of x′yzt′. The minimal cover uses two 2×2 blocks and a pair that wraps from the top row to the bottom row.

Watch out

Rectangles have 1, 2, 4 or 8 squares: no L-shapes and no blocks of 3 or 6. Remember the wraparound; in the 4-variable map the four corners form the rectangle yt. A larger rectangle is always better than a smaller one inside it, and a prime implicant may be left out if other primes already cover its squares.

3.6Truth tables and Boolean functions

Special sequences

For n inputs, use strings of length 2ⁿ. The first variable is 2ⁿ⁻¹ zeros followed by 2ⁿ⁻¹ ones; the next alternates in blocks of 2ⁿ⁻²; and so on, until the last alternates 0101…. Together they list all 2ⁿ input combinations, position k holding the binary form of k − 1.

x00001111x′11110000
y00110011y′11001100
z01010101z′10101010

For four inputs: A = 0000000011111111, B = 0000111100001111, C = 0011001100110011, D = 0101010101010101.

Truth table

T(E) is the output string when the inputs are the special sequences, written T(00001111, 00110011, 01010101) = … or simply T(E) = …. Each minterm has a single 1 (Table 5):

So x′yz = 00010000 and xyz′ = 00000010. A truth table is the graph of a Boolean function Bⁿ → B.

Algorithm 3

Truth table of an SoP. (1) Write the special sequences and their complements. (2) Compute each product: 1 only where all its factors are 1. (3) Add the products: 0 only where all are 0.

Example 16: Y = ABC + AB′C + A′B. ABC = 00000001, AB′C = 00000100, A′B = 00110000, so T(Y) = 00110101.

Backwards

From a truth table to an expression: a 1 in position k gives the minterm of k − 1 in binary, and E is the sum of these minterms. Example 20: T(E) = 01001001 has 1s in positions 2, 5 and 8, so E = x′y′z + xy′z′ + xyz. Then minimise it with a K-map.

P5.2

Write the dual

  1. x + x′y = x + y
  2. (x + 1)(y + 0) = y

P5.4

SoP, then CSoP

For each E(x, y, z), give an SoP form (Algorithm 1) and then the CSoP form (Algorithm 2). The checker tests the form as well as the value.

  1. E = (x + y)(x′ + z)
  2. E = (xy′ + z)′
  3. E = x′(y + z′)′ + yz
  4. E = (x′ + yz)(x + z′)′
Solution

(a) (x + y)(x′ + z) = xx′ + xz + x′y + yz = xz + x′y + yz. CSoP: xyz + xy′z + x′yz + x′yz′. (By consensus, xz + x′y is also a valid and shorter SoP.)

(b) (xy′ + z)′ = (xy′)′z′ = (x′ + y)z′ = x′z′ + yz′. CSoP: xyz′ + x′yz′ + x′y′z′.

(c) (y + z′)′ = y′z, so E = x′y′z + yz. CSoP: xyz + x′yz + x′y′z.

(d) (x + z′)′ = x′z, so E = (x′ + yz)x′z = x′z + x′yz = x′z. CSoP: x′yz + x′y′z.

P5.6

Prime implicants

P5.7

Sets as Boolean expressions

Write as a union of intersections and simplify, with + for ∪ and juxtaposition for ∩ (Exercise 1.3 style): (a) (A ∪ B′)′ ∩ (A ∪ C) (b) (A ∩ B)′ ∩ (A ∪ B)

Solution

(a) (A + B′)′(A + C) = A′B(A + C) = A′BA + A′BC = A′BC, that is A′ ∩ B ∩ C.

(b) (AB)′(A + B) = (A′ + B′)(A + B) = A′B + AB′, which is A ⊕ B.
