Sets and operations · Lecture 1

Task 1

Union and intersection of all Aₙ

Let Aₙ be the set of all positive integers divisible by n. Find (a) ⋃n=2∞ Aₙ and (b) ⋂n=2∞ Aₙ.

(a) ⋃n=2∞ Aₙ is

  • ∅
  • {1}
  • ℕ
  • ℕ ∖ {1} = {2, 3, 4, …}
  • the prime numbers

Every m ≥ 2 lies in Am, and 1 lies in no Aₙ with n ≥ 2.

(b) ⋂n=2∞ Aₙ is

  • ∅
  • {1}
  • A₂, the even numbers
  • ℕ

An element would have to be divisible by every n ≥ 2, including n = m + 1 > m.

Answer with reasons

(a) ⋃n=2∞ Aₙ = {2, 3, 4, …} = ℕ ∖ {1}. If m ≥ 2, then m is divisible by itself, so m ∈ Am and m is in the union. The number 1 is divisible by no n ≥ 2, so it is in none of the sets.

(b) ⋂n=2∞ Aₙ = ∅. Suppose m is in every Aₙ. Then m ∈ Am+1, so m + 1 divides m; but 0 < m < m + 1, a contradiction.

This is Exercise 2.9 of Lecture 1. Compare Exercise 1.6(c), where the union runs over the primes and gives the same answer.

Task 2

M is equivalent to M ∪ A

Let M be any infinite set and A any countable set. Prove that M is equivalent to M ∪ A.

Hint

Three ingredients from Part 4 of Lecture 1: the new elements are A ∖ M (Theorem 10 says how many there can be); M has a countable subset (Theorem 12); and two countable sets can be matched up (Theorem 11). Then copy the shift of P1.14.

Model proof

Let A₁ = A ∖ M. Then M ∪ A = M ∪ A₁ and M ∩ A₁ = ∅. As a subset of the countable set A, A₁ is finite or countable (Theorem 10). If A₁ = ∅, then M ∪ A = M and the identity map is a bijection. So assume A₁ ≠ ∅.

Since M is infinite, it contains a countable subset B = {b₁, b₂, b₃, …} (Theorem 12). The set B ∪ A₁ is countable (Theorem 11: a union of a countable and a finite or countable set). List it without repetition as c₁, c₂, c₃, …; then g(bₙ) = cₙ is a bijection g: B → B ∪ A₁.

Define f: M → M ∪ A by f(x) = g(x) for x ∈ B and f(x) = x for x ∈ M ∖ B. We have the disjoint unions

M = (M ∖ B) ∪ B and M ∪ A = (M ∖ B) ∪ (B ∪ A₁).

f maps M ∖ B onto itself by the identity and B onto B ∪ A₁ by the bijection g, and the pieces do not overlap. So f is one-to-one and onto, and M ~ M ∪ A. ∎

Explicit version of g (Hilbert's hotel). If A₁ = {α₁, …, αk} is finite: g(bₙ) = αₙ for n ≤ k and g(bₙ) = bn−k for n > k. If A₁ = {α₁, α₂, …} is countable: g(b2n−1) = bₙ and g(b2n) = αₙ.

Self-check for your proof
  • Did you use A ∖ M, so that elements of A already in M are not counted twice?
  • Did you cover the case where A ∖ M is finite (or empty), not only the countable case?
  • Did you find a countable subset of M and say why it exists?
  • Did you define an actual bijection and check both one-to-one and onto?
  • “Both sets are infinite, so they are equivalent” is not a proof: ℕ and ℝ are both infinite and not equivalent.

Task 3

Write, negate, translate

For each statement: (1) introduce propositions, (2) write it as a compound proposition, (3) negate it, (4) write the negation in English.

  1. If the teacher is absent, then some students do not complete their homework.
  2. All the students completed their homework and the teacher is present.
  3. Some of the students did not complete their homework or the teacher is absent.
Hint

Two propositions are enough for all three statements, as long as one of them is about all the students. Then “some students do not complete” is just its negation. Use ¬(p → q) ≡ p ∧ ¬q and De Morgan.

Model answer

(1) Let p = “The teacher is present” and q = “All the students completed their homework”. Then ¬p = “The teacher is absent” and ¬q = “Some students did not complete their homework”.

(2) Formula(3) Negation(4) In English
(a)¬p → ¬q¬(¬p → ¬q) ≡ ¬p ∧ qThe teacher is absent and all the students completed their homework.
(b)q ∧ p¬(q ∧ p) ≡ ¬q ∨ ¬pSome students did not complete their homework or the teacher is absent.
(c)¬q ∨ ¬p¬(¬q ∨ ¬p) ≡ q ∧ pAll the students completed their homework and the teacher is present.

Notice that (b) and (c) are negations of each other, which is a good check. Choosing p = “the teacher is absent” and q = “some students did not complete their homework” also works: the formulas change (for example (a) becomes p → q, negated to p ∧ ¬q), but the English answers are the same.

Task 4

Q(x): “x + 1 > 2x” over the integers

What are the truth values?

  1. Q(0)1 > 0.
  2. Q(−1)0 > −2.
  3. Q(1)2 > 2 is false.
  4. ∃x Q(x)x = 0 works.
  5. ∀x Q(x)x = 1 is a counterexample.
  6. ∃x ¬Q(x)x = 1.
  7. ∀x ¬Q(x)Q(0) is true.
Method

x + 1 > 2x ⟺ x < 1, so over the integers the truth set is TQ = {…, −2, −1, 0}. It is neither empty nor all of ℤ, which settles (d)–(g) at once.

(d) P(1) ∨ P(3) ∨ P(5)

2.2

SoP and CSoP forms

Express each E(x, y, z) as an SoP and then in CSoP form. The boxes check the form as well as the value.

  1. E = x(xy′ + x′y + y′z)
  2. E = (x + y′z)(y + z′)
  3. E = (x′ + y)′ + y′z
  4. E = (x′y)′(x′ + xyz′)
  5. E = (x + y)′(xy′)′
  6. E = y(x + yz)′
Hint

Algorithm 1: De Morgan first, then multiply out, kill xx′ products, absorb. Algorithm 2: multiply each short product by (v + v′) for each missing variable v.

Solution

(a) xxy′ + xx′y + xy′z = xy′ + 0 + xy′z = xy′ (absorption). CSoP: xy′(z + z′) = xy′z + xy′z′.

(b) xy + xz′ + y′zy + y′zz′ = xy + xz′. CSoP: xy(z + z′) + x(y + y′)z′ = xyz + xyz′ + xy′z′.

(c) (x′ + y)′ = xy′, so E = xy′ + y′z. CSoP: xy′z + xy′z′ + x′y′z (the product xy′z appears twice and is kept once).

(d) (x′y)′ = x + y′, so E = (x + y′)(x′ + xyz′) = xx′ + xyz′ + x′y′ + xyy′z′ = xyz′ + x′y′. CSoP: xyz′ + x′y′z + x′y′z′.

(e) (x + y)′ = x′y′ and (xy′)′ = x′ + y, so E = x′y′(x′ + y) = x′y′ + x′yy′ = x′y′. CSoP: x′y′z + x′y′z′.

(f) (x + yz)′ = x′(yz)′ = x′(y′ + z′), so E = yx′y′ + yx′z′ = x′yz′, which is already a minterm.

2.3

Minimal SoP forms

  1. E₁ = xy′z′ + x′y + x′y′z′ + x′yz
  2. E₂ = xy′ + x′z′t + xyzt′ + x′y′zt′
  3. E₃ = xyzt + xyz′t′ + xz′t′ + x′y′z′ + x′yz′t
Hint

Draw the map (3 variables for E₁, 4 for the others), expanding each product into all its squares. E₃ has two different minimal sums.

Answer

(a) E₁ = x′y + y′z′. The squares are xy′z′, x′yz, x′yz′, x′y′z′; the prime implicants are x′y, x′z′, y′z′, of which x′y and y′z′ are essential and already cover everything.

(b) E₂ = xy′ + xzt′ + x′z′t + y′zt′, unique (4 products, 11 literals). All four are essential.

(c) Two minimal sums: E₃ = xyzt + xz′t′ + x′z′t + y′z′t′ and E₃ = xyzt + xz′t′ + x′z′t + x′y′z′. The square xyzt is isolated, so it stays a 4-literal product; xz′t′ and x′z′t are essential; the square x′y′z′t′ can go with either neighbour.

2.14

Three switches, one hall light

The light is on (1) when an odd number of the switches A, B, C are up. (a) Show that T(A, B, C) = 01101001 satisfies the conditions. (b) Design a minimal AND–OR circuit with this truth table.

Hint

For (a), count the 1s in each input column 000, 001, …, 111. For (b), draw the map and look for adjacent checked squares.

Answer

(a) The inputs in order are 000, 001, 010, 011, 100, 101, 110, 111, with 0, 1, 1, 2, 1, 2, 2, 3 ones. The odd counts are in positions 2, 3, 5, 8, which is exactly where 01101001 has its 1s. Changing any one switch changes the count by one and so flips the parity, which toggles the light; so each switch controls the light from any state.

(b) L = A′B′C + A′BC′ + AB′C′ + ABC. On the map the four squares form a checkerboard: no two are adjacent, so every square is its own prime implicant and this CSoP is already minimal (this is A ⊕ B ⊕ C).
