Proof practice · Lectures 1–5 · easy to hard

Proofs, step by step

Every midterm so far ends with proofs: De Morgan's laws, countability, infinite sets. This section collects the proofs of the course in seven levels, from one-line arguments to Cantor's theorem. Most come from the theorems and exercises in the lecture notes; a few come from other discrete-structures courses (credited where they appear). Try each one on paper first, then open the model proof. Some problems are puzzles: put the steps of the proof in the right order. Others show a wrong “proof” and ask you to find the broken step.

Proof toolbox

  • Two sets are equal (X = Y): take any x and show x ∈ X ⟹ x ∈ Y and x ∈ Y ⟹ x ∈ X, or write one chain of ⟺. Or rewrite one side into the other with the laws of the algebra of sets.
  • A subset (X ⊆ Y): “Let x ∈ X. … Hence x ∈ Y.”
  • Not true in general: one counterexample with concrete sets (or numbers) is a complete proof.
  • Logical equivalence: a chain of laws from Table 14, or a truth table. Quantifiers: show that each side being true forces the other to be true, for every domain and every predicate.
  • Boolean algebra: use only the axioms [B1]–[B4] and laws already proved, and name one in every step. Prove one law; its dual follows by duality.
  • Countable: an explicit bijection with ℤ⁺, or Theorem 10 (an infinite subset of a countable set is countable), or Theorem 11 (a finite or countable union of countable sets is countable). Uncountable: assume a list exists and build an element that is not on it (diagonal argument), or find an uncountable subset.
  • Marking: the exam wants a proof, “not an explanation”. Start from what is given, justify each step, and end with what was to be proved (∎).

Level 1 · Warm-up: one-line proofs

P1

Intersection and union

Prove that for any sets A, B: A ∩ B ⊆ A ⊆ A ∪ B. (Theorem 3, Lecture 1.)

Model proof

Let x ∈ A ∩ B. Then x ∈ A and x ∈ B; in particular x ∈ A. So A ∩ B ⊆ A.

Let x ∈ A. Then the statement “x ∈ A or x ∈ B” is true, so x ∈ A ∪ B. So A ⊆ A ∪ B. ∎

P2

Difference as an intersection

Prove that B ∖ A = B ∩ A′. (Solved problem 1.4, Lecture 1.)

Model proof

x ∈ B ∖ A ⟺ x ∈ B ∧ x ∉ A ⟺ x ∈ B ∧ x ∈ A′ ⟺ x ∈ B ∩ A′.

The steps use the definitions of difference, complement and intersection. Both sets have the same elements. ∎

This identity is the most useful tool for differences: it turns every ∖ into ∩ and ′, so the laws of Table 1 apply.

P3

Absorption laws

Prove that A ∪ (A ∩ B) = A and A ∩ (A ∪ B) = A. (Exercise 2.4, Lecture 1.)

Hint

Two inclusions. One of them is P1.

Model proof

⊆: let x ∈ A ∪ (A ∩ B). Then x ∈ A or x ∈ A ∩ B. In the second case also x ∈ A. So x ∈ A either way.

⊇: A ⊆ A ∪ (A ∩ B) by P1. So A ∪ (A ∩ B) = A.

Second law: A ∩ (A ∪ B) ⊆ A by P1. If x ∈ A, then x ∈ A ∪ B (P1), so x ∈ A ∩ (A ∪ B). ∎

P4

Equivalences by the laws of logic

Using the laws of Table 14 (no truth tables), prove (a) ¬(p → q) ≡ p ∧ ¬q; (b) (p ∧ q) → (p ∨ q) is a tautology. (Examples 19 and 21, Lectures 2–3.)

Hint

Start with p → q ≡ ¬p ∨ q. In (b), regroup so that p meets ¬p.

Model proof

(a) ¬(p → q) ≡ ¬(¬p ∨ q) ≡ ¬¬p ∧ ¬q ≡ p ∧ ¬q (conditional law, De Morgan, double negation).

(b) (p ∧ q) → (p ∨ q) ≡ ¬(p ∧ q) ∨ (p ∨ q) ≡ (¬p ∨ ¬q) ∨ (p ∨ q) ≡ (¬p ∨ p) ∨ (¬q ∨ q) ≡ T ∨ T ≡ T (conditional law, De Morgan, associative and commutative laws, negation law, domination). ∎

P5

Puzzle: De Morgan for sets

Put the steps of the proof of (A ∪ B)′ = A′ ∩ B′ in order. (This is a midterm task every year.)

  1. Let x ∈ S be any element.
  2. x ∈ (A ∪ B)′ ⟺ x ∉ A ∪ B (definition of complement)
  3. ⟺ ¬(x ∈ A ∨ x ∈ B) (definition of union)
  4. ⟺ x ∉ A ∧ x ∉ B (De Morgan's law for propositions)
  5. ⟺ x ∈ A′ ∧ x ∈ B′ (definition of complement)
  6. ⟺ x ∈ A′ ∩ B′ (definition of intersection)
  7. So the two sets have the same elements: (A ∪ B)′ = A′ ∩ B′. ∎

Level 2 · Set identities and subsets

P6

Three ways to say A ⊆ B

Prove that the following are equivalent: (1) A ⊆ B; (2) A ∩ B = A; (3) A ∪ B = B. (Theorem 4, Lecture 1.)

Hint

Prove a cycle (1) ⟹ (2) ⟹ (3) ⟹ (1). Three implications are enough for three equivalences.

Model proof

(1) ⟹ (2). A ∩ B ⊆ A always (P1). If x ∈ A, then x ∈ B by (1), so x ∈ A ∩ B. Hence A ∩ B = A.

(2) ⟹ (3). B ⊆ A ∪ B always. If x ∈ A ∪ B, then either x ∈ B, or x ∈ A = A ∩ B, and then x ∈ B too. Hence A ∪ B = B.

(3) ⟹ (1). If x ∈ A, then x ∈ A ∪ B = B. Hence A ⊆ B. ∎

P7

When union and intersection agree

Prove: if A ∪ B = A and A ∩ B = A, then A = B. (Exercise 2.2, Lecture 1.)

Model proof

B ⊆ A ∪ B = A, and A = A ∩ B ⊆ B (both by P1). So A ⊆ B and B ⊆ A, that is, A = B. ∎

P8

Two forms of the symmetric difference

Prove (A ∪ B) ∖ (A ∩ B) = (A ∖ B) ∪ (B ∖ A) using the laws of the algebra of sets. (Solved problem 1.5, Lecture 1.)

Hint

Replace both differences using P2, apply De Morgan, then distribute.

Model proof

(A ∪ B) ∖ (A ∩ B) = (A ∪ B) ∩ (A ∩ B)′ = (A ∪ B) ∩ (A′ ∪ B′)

= (A ∩ A′) ∪ (A ∩ B′) ∪ (B ∩ A′) ∪ (B ∩ B′) = ∅ ∪ (A ∩ B′) ∪ (B ∩ A′) ∪ ∅

= (A ∩ B′) ∪ (B ∩ A′) = (A ∖ B) ∪ (B ∖ A).

Laws used: P2, De Morgan, distributive (twice), complement, identity, P2 again. ∎

P9

A difference of differences

Prove (A − B) − C = (A − C) − (B − C). (From UC Davis ECS 20 homework.)

Hint

Start from the right side, write membership as a proposition, apply De Morgan, distribute, and one term becomes x ∈ C ∧ x ∉ C, which is false.

Model proof

x ∈ (A − C) − (B − C) ⟺ (x ∈ A ∧ x ∉ C) ∧ ¬(x ∈ B ∧ x ∉ C)

⟺ (x ∈ A ∧ x ∉ C) ∧ (x ∉ B ∨ x ∈ C)

⟺ (x ∈ A ∧ x ∉ C ∧ x ∉ B) ∨ (x ∈ A ∧ x ∉ C ∧ x ∈ C)

⟺ (x ∈ A ∧ x ∉ B ∧ x ∉ C) ∨ F ⟺ x ∈ (A − B) − C.

Definitions, De Morgan, distributive law, negation and identity laws. ∎

P10

Taking away and putting back

(a) Show that in general (A − B) ∪ B ≠ A. (b) Prove (A − B) ∪ B = A ∪ B. (c) Deduce that (A − B) ∪ B = A exactly when B ⊆ A. (Exercise 2.5, Lecture 1.)

Model proof

(a) Counterexample: A = {1}, B = {2}. Then (A − B) ∪ B = {1} ∪ {2} = {1, 2} ≠ A.

(b) (A − B) ∪ B = (A ∩ B′) ∪ B = (A ∪ B) ∩ (B′ ∪ B) = (A ∪ B) ∩ U = A ∪ B (P2, distributive, complement, identity).

(c) By (b), (A − B) ∪ B = A ⟺ A ∪ B = A ⟺ B ⊆ A, by P6 with the roles of A and B swapped. ∎

P11

Distributive law, by elements

Prove A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) by an element argument. (One of the two laws proved in Theorem 6, Lecture 1.)

Model proof

x ∈ A ∩ (B ∪ C) ⟺ x ∈ A ∧ (x ∈ B ∨ x ∈ C) ⟺ (x ∈ A ∧ x ∈ B) ∨ (x ∈ A ∧ x ∈ C) ⟺ x ∈ (A ∩ B) ∨ x ∈ (A ∩ C) ⟺ x ∈ (A ∩ B) ∪ (A ∩ C).

The second step is the distributive law of propositions; the others are definitions. ∎

Notice the pattern: every law of sets is the matching law of logic applied to the statements “x ∈ A”, “x ∈ B”, “x ∈ C”.

P12

Find the flaw: a union minus a set

A student claims (A ∪ B) − B = A for all sets and writes:

(1) x ∈ (A ∪ B) − B ⟺ x ∈ A ∪ B ∧ x ∉ B (2) ⟺ (x ∈ A ∨ x ∈ B) ∧ x ∉ B (3) ⟺ x ∈ A.

Which step is wrong?

  • Step (1)
  • Step (2)
  • Step (3)
  • None: the claim is true

Step (3) drops the condition x ∉ B. Correctly, (x ∈ A ∨ x ∈ B) ∧ x ∉ B ⟺ x ∈ A ∧ x ∉ B, so (A ∪ B) − B = A − B. Counterexample to the claim: A = B = {1} gives (A ∪ B) − B = ∅ ≠ A. The claim holds only when A ∩ B = ∅.

P13

Always true or not?

For each statement, decide whether it holds for all sets. If it does, prove it; if not, find a counterexample.

  1. A − (B ∪ C) = (A − B) ∩ (A − C)A ∩ (B ∪ C)′ = A ∩ B′ ∩ C′ = (A ∩ B′) ∩ (A ∩ C′) (De Morgan, idempotent law).
  2. A − (B − C) = (A − B) − CA = C = {1}, B = ∅: left side {1}, right side ∅.
  3. P(A ∩ B) = P(A) ∩ P(B)X ⊆ A ∩ B ⟺ X ⊆ A ∧ X ⊆ B.
  4. P(A ∪ B) = P(A) ∪ P(B)A = {1}, B = {2}: {1, 2} is in the left side only.
  5. A ⊆ B ⟹ B′ ⊆ A′If x ∉ B, then x ∉ A; otherwise x ∈ A ⊆ B.

Level 3 · Logic and quantifiers

P14

De Morgan for quantifiers

Prove ¬∀x P(x) ≡ ∃x ¬P(x), then deduce ¬∃x P(x) ≡ ∀x ¬P(x). (Theorems 7 and 8, Lectures 2–3.)

Model proof

Fix any domain and any predicate P. ¬∀x P(x) is true ⟺ ∀x P(x) is false ⟺ there is an a in the domain with P(a) false ⟺ there is an a with ¬P(a) true ⟺ ∃x ¬P(x) is true. Both sides always have the same truth value.

For the second law, apply the first to the predicate ¬P: ¬∀x ¬P(x) ≡ ∃x ¬¬P(x) ≡ ∃x P(x). Negating both sides gives ∀x ¬P(x) ≡ ¬∃x P(x). ∎

P15

∀ distributes over ∧

Prove ∀x(P(x) ∧ Q(x)) ≡ ∀x P(x) ∧ ∀x Q(x). (Theorem 6(a), Lectures 2–3.)

Model proof

(⟹) Suppose ∀x(P(x) ∧ Q(x)) is true. Let a be any element of the domain. Then P(a) ∧ Q(a) is true, so P(a) is true and Q(a) is true. As a was arbitrary, ∀x P(x) and ∀x Q(x) are both true.

(⟸) Suppose ∀x P(x) and ∀x Q(x) are true. For any a, P(a) and Q(a) are true, so P(a) ∧ Q(a) is true. Hence ∀x(P(x) ∧ Q(x)). ∎

P16

Where the quantifier laws stop

Show that (a) ∀x P(x) ∨ ∀x Q(x) and ∀x(P(x) ∨ Q(x)) are not equivalent; (b) ∃x P(x) ∧ ∃x Q(x) and ∃x(P(x) ∧ Q(x)) are not equivalent. (Exercises 2.16 and 2.17, Lectures 2–3.)

Hint

One domain and one pair of predicates works for both: integers, “x is even”, “x is odd”.

Model proof

Domain ℤ, P(x): “x is even”, Q(x): “x is odd”.

(a) ∀x(P(x) ∨ Q(x)) is true: every integer is even or odd. But ∀x P(x) is false (x = 1) and ∀x Q(x) is false (x = 2), so ∀x P(x) ∨ ∀x Q(x) is false.

(b) ∃x P(x) (take 2) and ∃x Q(x) (take 1) are true, so the left side is true. No integer is both even and odd, so ∃x(P(x) ∧ Q(x)) is false. ∎

One direction does hold in each case: ∀x P ∨ ∀x Q ⟹ ∀x(P ∨ Q) and ∃x(P ∧ Q) ⟹ ∃x P ∧ ∃x Q.

P17

Negating “all P are Q”

Prove ¬∀x(P(x) → Q(x)) ≡ ∃x(P(x) ∧ ¬Q(x)). (Example 34, Lectures 2–3.)

Model proof

¬∀x(P(x) → Q(x)) ≡ ∃x ¬(P(x) → Q(x)) ≡ ∃x(P(x) ∧ ¬Q(x)).

The first step is P14; the second is P4(a) applied inside the quantifier. ∎

In words: “not every P is a Q” means “some P is not a Q”.

P18

Proof by contradiction: chaining implications

Prove that [(p → q) ∧ (q → r)] → (p → r) is a tautology without a truth table.

Hint

An implication is false only when its premise is true and its conclusion is false. Assume that happens.

Model proof

Suppose that for some truth values the proposition is false. Then its premise (p → q) ∧ (q → r) is true and its conclusion p → r is false. From the conclusion, p is true and r is false. Since p is true and p → q is true, q is true. Since q is true and q → r is true, r is true. That contradicts “r is false”. So the proposition is never false: it is a tautology. ∎

Level 4 · Functions, images and preimages

P19

Compositions

Let f : X → Y and g : Y → Z. Prove: (a) if f, g are injective, so is g ∘ f; (b) if f, g are surjective, so is g ∘ f. Deduce that equivalence of sets is transitive: X ∼ Y and Y ∼ Z give X ∼ Z.

Model proof

(a) Let (g ∘ f)(x₁) = (g ∘ f)(x₂), i.e. g(f(x₁)) = g(f(x₂)). Since g is injective, f(x₁) = f(x₂); since f is injective, x₁ = x₂.

(b) Let z ∈ Z. Since g is onto, z = g(y) for some y ∈ Y; since f is onto, y = f(x) for some x ∈ X. Then (g ∘ f)(x) = z.

If f : X → Y and g : Y → Z are bijections, then by (a) and (b) g ∘ f : X → Z is a bijection, so X ∼ Z. ∎

P20

Puzzle: preimage of a union

Put the steps of the proof of f⁻¹(A ∪ B) = f⁻¹(A) ∪ f⁻¹(B) in order. (Theorem 7, Lecture 1. The same chain with ∧ proves Theorem 8, f⁻¹(A ∩ B) = f⁻¹(A) ∩ f⁻¹(B).)

  1. Let f : X → Y, A, B ⊆ Y, and let x ∈ X.
  2. x ∈ f⁻¹(A ∪ B) ⟺ f(x) ∈ A ∪ B (definition of preimage)
  3. ⟺ f(x) ∈ A ∨ f(x) ∈ B (definition of union)
  4. ⟺ x ∈ f⁻¹(A) ∨ x ∈ f⁻¹(B) (definition of preimage)
  5. ⟺ x ∈ f⁻¹(A) ∪ f⁻¹(B) (definition of union)
  6. So both sets have the same elements. ∎
P21

Complements: preimage yes, image no

Let f : X → Y, B ⊆ Y. (a) Prove f⁻¹(Y − B) = X − f⁻¹(B). (b) Is f(X − A) = Y − f(A) for every A ⊆ X? Prove it or give a counterexample. (Exercise 2.8, Lecture 1.)

Model proof

(a) For x ∈ X: x ∈ f⁻¹(Y − B) ⟺ f(x) ∈ Y − B ⟺ f(x) ∉ B ⟺ x ∉ f⁻¹(B) ⟺ x ∈ X − f⁻¹(B). ∎

(b) No. Let X = {1, 2}, Y = {a, b}, f(1) = f(2) = a, A = {1}. Then f(X − A) = f({2}) = {a}, but Y − f(A) = {a, b} − {a} = {b}.

The equality does hold when f is a bijection: injectivity gives f(X − A) ⊆ Y − f(A) and surjectivity gives ⊇.

P22

Images of unions and intersections

Prove f(A ∪ B) = f(A) ∪ f(B) (Theorem 9, Lecture 1) and f(A ∩ B) ⊆ f(A) ∩ f(B). Show that the second inclusion can be strict.

Model proof

y ∈ f(A ∪ B) ⟺ ∃x ∈ A ∪ B with f(x) = y ⟺ (∃x ∈ A with f(x) = y) ∨ (∃x ∈ B with f(x) = y) ⟺ y ∈ f(A) ∪ f(B). The middle step is “∃ distributes over ∨”.

If y ∈ f(A ∩ B), then y = f(x) with x ∈ A and x ∈ B, so y ∈ f(A) and y ∈ f(B).

Strict: f(x) = x² on ℝ, A = {−1}, B = {1}. Then f(A ∩ B) = f(∅) = ∅ but f(A) ∩ f(B) = {1}. ∎

P23

Find the flaw: image of an intersection

A “proof” that f(A) ∩ f(B) ⊆ f(A ∩ B):

(1) Let y ∈ f(A) ∩ f(B). (2) Then y ∈ f(A) and y ∈ f(B). (3) So y = f(x) for some x ∈ A, and y = f(x) for some x ∈ B. (4) Hence y = f(x) with x ∈ A ∩ B, so y ∈ f(A ∩ B).

Where does it go wrong?

  • Step (2): the definition of intersection is misused
  • Step (3): y ∈ f(A) does not mean y = f(x) for some x ∈ A
  • Nowhere: the inclusion is true
  • Step (4): the two elements called x may be different

Step (3) should say y = f(x₁) with x₁ ∈ A and y = f(x₂) with x₂ ∈ B. Nothing forces x₁ = x₂ unless f is injective. P22 gives a counterexample. Using one letter for two different objects is a classic error.

Level 5 · Boolean algebra from the axioms

The axioms (Lectures 4–5)

  • [B1] commutative: a + b = b + a, ab = ba
  • [B2] distributive: a + bc = (a + b)(a + c), a(b + c) = ab + ac
  • [B3] identity: a + 0 = a, a · 1 = a
  • [B4] complement: a + a′ = 1, aa′ = 0

Nothing else may be used unless it has already been proved from these. In particular, a truth table is not a proof here: an arbitrary Boolean algebra need not be {0, 1}.

P24

Puzzle: idempotent law

Put the steps of the proof of aa = a (B5b) in order. Then a + a = a follows by duality.

  1. a = a · 1 [B3b]
  2. = a(a + a′) [B4a]
  3. = aa + aa′ [B2b]
  4. = aa + 0 [B4b]
  5. = aa [B3a] ∎
P25

Boundedness and absorption

From the axioms, prove (a) a · 0 = 0 (B6b); (b) a(a + b) = a (B7b). State the duals.

Hint

(a) Write a0 as a0 + aa′. (b) Write the first a as a + 0, then use [B2a] backwards.

Model proof

(a) a0 = a0 + 0 = a0 + aa′ = a(0 + a′) = a(a′ + 0) = aa′ = 0 [B3a, B4b, B2b, B1, B3a, B4b].

(b) a(a + b) = (a + 0)(a + b) = a + 0b = a + b0 = a + 0 = a [B3a, B2a, B1, (a), B3a].

Duals: a + 1 = 1 (B6a) and a + ab = a (B7a). ∎

P26

A useful shortcut

Prove a + a′b = a + b and state its dual.

Model proof

a + a′b = (a + a′)(a + b) = 1 · (a + b) = (a + b) · 1 = a + b [B2a, B4a, B1, B3b].

Dual: a(a′ + b) = ab. ∎

This is the step behind many K-map simplifications, e.g. x + x′y = x + y.

P27

Uniqueness of the complement

Prove (B9): if a + x = 1 and ax = 0, then x = a′.

Hint

Show that both x and a′ equal x + a′. Start each from “… + 0” and replace the 0 by the right product.

Model proof

x = x + 0 = x + aa′ = (x + a)(x + a′) = (a + x)(x + a′) = 1 · (x + a′) = x + a′ [B3a, B4b, B2a, B1, hypothesis, B1 + B3b]

a′ = a′ + 0 = a′ + ax = (a′ + a)(a′ + x) = 1 · (a′ + x) = a′ + x = x + a′ [B3a, hypothesis, B2a, B1 + B4a, B1 + B3b, B1]

Both equal x + a′, so x = a′. ∎

P28

Involution and the complements of 0 and 1

Using P27, prove (a′)′ = a (B10) and 0′ = 1, 1′ = 0 (B11).

Model proof

By [B4] and [B1], a′ + a = 1 and a′a = 0. So a satisfies the two conditions of a complement of a′, and by P27, a = (a′)′.

0 + 1 = 1 + 0 = 1 [B1, B3a] and 0 · 1 = 0 [B3b]. So 1 is a complement of 0: 0′ = 1 by P27. By duality, 1′ = 0. ∎

P29

De Morgan in a Boolean algebra

Prove (a + b)′ = a′b′ (Theorem 7, Lectures 4–5; left as an exercise there). You may use the laws B5–B9.

Hint

Use uniqueness (P27): it is enough to show (a + b) + a′b′ = 1 and (a + b) · a′b′ = 0.

Model proof

Sum: (a + b) + a′b′ = ((a + b) + a′)((a + b) + b′) [B2a]. Here (a + b) + a′ = (a + a′) + b = 1 + b = 1 [B1, B8a, B4a, B6a], and (a + b) + b′ = a + (b + b′) = a + 1 = 1 [B8a, B4a, B6a]. So the sum is 1 · 1 = 1.

Product: (a + b)(a′b′) = a(a′b′) + b(a′b′) = (aa′)b′ + a′(bb′) = 0 · b′ + a′ · 0 = 0 + 0 = 0 [B2b, B1 + B8b, B4b, B1 + B6b, B3a].

By P27, a′b′ is the complement of a + b. By duality, (ab)′ = a′ + b′. ∎

P30

Four ways to say a ≤ b

Prove that these are equivalent (Theorem 8, Lectures 4–5): (1) a + b = b; (2) ab = a; (3) a′ + b = 1; (4) ab′ = 0.

Hint

A cycle (1) ⟹ (2) ⟹ (4) ⟹ (3) ⟹ (1) works well. For the last step, multiply a + b by 1 = a′ + b.

Model proof

(1) ⟹ (2): ab = a(a + b) = a (substitute (1), then absorption B7b).

(2) ⟹ (4): ab′ = (ab)b′ = a(bb′) = a0 = 0 (substitute (2), B8b, B4b, B6b).

(4) ⟹ (3): a′ + b = a′ + b″ = (ab′)′ = 0′ = 1 (B10, De Morgan P29, substitute (4), B11).

(3) ⟹ (1): a + b = (a + b) · 1 = (b + a)(b + a′) = b + aa′ = b + 0 = b (B3b, substitute (3) and B1, B2a, B4b, B3a). ∎

In the algebra of sets these say: A ∪ B = B, A ∩ B = A, A′ ∪ B = U, A − B = ∅, i.e. A ⊆ B (compare P6).

Level 6 · Countable sets

Proofs of this kind already in the midterm sections: polynomials with rational coefficients, rational points of the plane, rational intervals, every infinite set is equivalent to a proper subset.

P31

The integers are countable

Prove that f : ℤ → ℤ⁺, f(n) = 2n + 1 for n ≥ 0 and f(n) = 2|n| for n < 0, is a bijection. (Example 14, Lecture 1.)

Model proof

Well defined: for n ≥ 0, 2n + 1 ≥ 1 is odd; for n < 0, 2|n| ≥ 2 is even. So f(n) ∈ ℤ⁺.

Injective: an odd value never equals an even value, so if f(n) = f(m) then n, m have the same sign. If both are ≥ 0, 2n + 1 = 2m + 1 gives n = m; if both are negative, 2|n| = 2|m| gives n = m.

Surjective: an odd k is f((k − 1)/2) with (k − 1)/2 ≥ 0; an even k is f(−k/2) with −k/2 < 0. ∎

P32

Subsets of countable sets

Using Theorem 10 (“every subset of a countable set is finite or countable”), prove that the set of prime numbers and the set of perfect squares are countable.

Model proof

Both are subsets of the countable set ℤ⁺, so each is finite or countable. Neither is finite. For the squares, n ↦ n² is injective on ℤ⁺. For the primes, suppose there were only finitely many, p₁, …, pₖ. Then N = p₁p₂⋯pₖ + 1 leaves remainder 1 when divided by every pᵢ, so any prime factor of N is a new prime, a contradiction (Euclid). Hence both sets are countable. ∎

P33

Pairs of positive integers

Prove that g : ℤ⁺ × ℤ⁺ → ℤ⁺, g(m, n) = 2ᵐ⁻¹(2n − 1), is a bijection. Hence ℤ⁺ × ℤ⁺ is countable.

Hint

Every positive integer can be written in exactly one way as a power of 2 times an odd number.

Model proof

Surjective: let k ∈ ℤ⁺. Divide k by 2 as often as possible: k = 2ᵃ · q with a ≥ 0 and q odd. Put m = a + 1 and n = (q + 1)/2; then g(m, n) = k.

Injective: if 2ᵐ⁻¹(2n − 1) = 2ᵐ′⁻¹(2n′ − 1) and, say, m > m′, divide by 2ᵐ′⁻¹: the left side is even and the right side is odd, which is impossible. So m = m′, and then 2n − 1 = 2n′ − 1 gives n = n′. ∎

This replaces the diagonal picture (4.2) in the proof of Theorem 11 with a formula.

P34

The rationals, via Theorem 11

Give a proof that ℚ is countable using Theorem 11 instead of “heights” (Example 17).

Model proof

For each q ∈ ℤ⁺ let Q_q = {p/q : p ∈ ℤ}. The map p ↦ p/q is a bijection ℤ → Q_q, so each Q_q is countable (P31 and transitivity, P19). Every rational can be written with a positive denominator, so ℚ = ⋃q∈ℤ⁺ Q_q: a countable union of countable sets. By Theorem 11, ℚ is countable. ∎

The sets Q_q overlap (1/1 = 2/2); Theorem 11 allows that, as its proof first makes the sets disjoint.

P35

Algebraic numbers

A number is algebraic if it is a root of a nonzero polynomial with rational coefficients. Prove that the set of algebraic numbers is countable. (Exercise 2.12, Lecture 1.)

Hint

Polynomials with rational coefficients form a countable set (midterm proof), and a nonzero polynomial of degree n has at most n roots.

Model proof

Let 𝒫 be the set of nonzero polynomials with rational coefficients; it is countable (a subset of a countable set, infinite). For P ∈ 𝒫 let R(P) be its set of roots; it is finite (at most deg P elements). The set of algebraic numbers is 𝔸 = ⋃P∈𝒫 R(P), a countable union of finite sets, so it is finite or countable: list the polynomials as P₁, P₂, …, then list the roots of P₁, then those of P₂, and so on, skipping repeats. It is infinite, because every rational r is the root of t − r. Hence 𝔸 is countable. ∎

P36

Adding a countable set changes nothing

Let M be infinite and A countable. Prove M ∪ A ∼ M. (Exercise 2.15*, Lecture 1.)

Hint

Copy the idea of Theorem 13: find a countable C ⊆ M (Theorem 12), map C ∪ A onto C, and leave the rest of M fixed.

Model proof

Let A₀ = A − M; then M ∪ A = M ∪ A₀ with M ∩ A₀ = ∅, and A₀ is finite or countable (Theorem 10). If A₀ = ∅ there is nothing to prove.

By Theorem 12, M has a countable subset C. Then C ∪ A₀ is countable (Theorem 11; a finite set can be listed first). So there is a bijection g : C ∪ A₀ → C, since both are countable.

Define h : M ∪ A₀ → M by h(x) = g(x) for x ∈ C ∪ A₀ and h(x) = x for x ∈ M − C. The two parts C ∪ A₀ and M − C partition M ∪ A₀, their images C and M − C partition M, and h is a bijection on each part. So h is a bijection and M ∪ A ∼ M. ∎

P37

Find the flaw: listing infinite sequences

“The set S of all infinite sequences of 0s and 1s is countable: list first the sequences that start with 0, then those that start with 1. Within each group, order by the second digit, and so on. Every sequence gets a place in the list.”

What is wrong with this argument?

  • Nothing: S is countable, by Theorem 11
  • “Every sequence gets a place” is never shown, and it is false: already the first group is infinite, so no sequence of the second group gets a finite position
  • The groups overlap, so the list has repetitions
  • Sequences of 0s and 1s are finite, so the list is finite

A list must give every element a finite position 1, 2, 3, …. “Sort by first digit, then second, …” is an infinite sorting that never finishes the first group. In fact S is uncountable: the diagonal argument (P40) applies word for word, flipping the n-th digit of the n-th sequence.

P38

A set with an uncountable subset

Prove that a set with an uncountable subset is itself uncountable. (Exercise 2.17, Lecture 1.)

Model proof

Let B ⊆ M with B uncountable, and suppose M is not uncountable, i.e. M is finite or countable. If M is finite, so is its subset B. If M is countable, B is finite or countable by Theorem 10. Either way B is not uncountable, a contradiction. ∎

P39

Intervals and the real line

(a) For a < b and c < d, prove [a, b] ∼ [c, d] with an explicit bijection (Example 19 does it geometrically). (b) Prove (0, 1) ∼ ℝ.

Model proof

(a) f(x) = c + (d − c)(x − a)/(b − a) maps a ↦ c and b ↦ d, and is increasing, so it maps [a, b] into [c, d]. Its inverse g(y) = a + (b − a)(y − c)/(d − c) maps [c, d] into [a, b], and g(f(x)) = x, f(g(y)) = y. A function with a two-sided inverse is a bijection.

(b) h(x) = tan(π(x − ½)): as x runs over (0, 1), π(x − ½) runs over (−π/2, π/2), and tan is a bijection from there onto ℝ (Example 4). A composition of bijections is a bijection (P19). ∎

With P38: [0, 1] is uncountable (P40), so ℝ and every interval [c, d] are uncountable.

P40

Puzzle: Cantor's diagonal argument

Put the steps of the proof that [0, 1] is uncountable (Theorem 14, Lecture 1) in order. Using only the digits 4 and 5 avoids numbers with two decimal expansions, such as 0.1999… = 0.2000….

  1. Assume the contrary: [0, 1] is countable, so its elements can be listed as α₁, α₂, α₃, …
  2. Write each in decimal: αₙ = 0.aₙ₁aₙ₂aₙ₃…
  3. Define β = 0.b₁b₂b₃… by bₙ = 5 if aₙₙ ≠ 5 and bₙ = 4 if aₙₙ = 5.
  4. Then β ∈ [0, 1], and its expansion is the only one it has, because it contains no 0s or 9s.
  5. For every n, β and αₙ differ in the n-th digit, so β ≠ αₙ.
  6. So β is not in the list, which contradicts the assumption that the list contains all of [0, 1]. ∎
P41

Transcendental numbers exist, uncountably many

Prove that the set of real numbers that are not algebraic is uncountable. (Exercise 2.16*, Lecture 1.)

Model proof

Let 𝔸_ℝ be the real algebraic numbers and T = ℝ − 𝔸_ℝ. 𝔸_ℝ is countable (an infinite subset of the countable set in P35). Suppose T were finite or countable. Then ℝ = 𝔸_ℝ ∪ T would be countable by Theorem 11. But ℝ is uncountable (P39 with P38). So T is uncountable; in particular it is not empty. ∎

The proof shows that transcendental numbers exist without exhibiting a single one. Proving that a specific number such as π or e is transcendental is much harder.

P42

Closed and open intervals

Prove [0, 1] ∼ (0, 1) with an explicit bijection.

Hint

Two points too many. Make room in a countable sequence inside (0, 1), such as ½, ⅓, ¼, …, by shifting it two places, the same trick as in Theorem 13.

Model proof

Define h : [0, 1] → (0, 1): h(0) = ½, h(1) = ⅓, h(1/n) = 1/(n + 2) for n ≥ 2, and h(x) = x for every other x.

Let E = {1/n : n ≥ 2}. h maps {0, 1} ∪ E one-to-one onto E: 0, 1, ½, ⅓, … go to ½, ⅓, ¼, ⅕, …, which is all of E without repetition. It maps the rest, (0, 1) − E, identically onto itself. These two pieces partition [0, 1] and their images partition (0, 1), so h is a bijection. ∎

The same idea gives a general fact (from IIT Kharagpur CS60005 tutorial solutions): if A is uncountable and B ⊆ A is countable, then A − B ∼ A. Take a countable C = {c₁, c₂, …} ⊆ A − B and send bₙ ↦ c₂ₙ₋₁, cₙ ↦ c₂ₙ, everything else to itself.

P43

Cantor's theorem: |M| < |P(M)|

Prove that for every set M there is no surjection f : M → P(M), while there is an injection M → P(M). So the power set always has strictly larger cardinality. (Behind Exercise 2.18*, Lecture 1.)

Hint

Given f, look at the elements that do not belong to their own image: D = {x ∈ M : x ∉ f(x)}. Could D = f(d)?

Model proof

The map x ↦ {x} is injective, so |M| ≤ |P(M)|.

Let f : M → P(M) be any function and D = {x ∈ M : x ∉ f(x)} ∈ P(M). Suppose D = f(d) for some d ∈ M. If d ∈ D, then by the definition of D, d ∉ f(d) = D. If d ∉ D = f(d), then by the definition of D, d ∈ D. Both cases are impossible, so D is not in the image of f: no f is onto. Hence there is no bijection and |M| < |P(M)|. ∎

Exercise 2.18 follows: a function M → {0, 1} is the same as a subset of M (the set where it equals 1), so the set of all such functions has cardinality |P(M)| > |M|. Note that this is the diagonal argument again: D differs from f(x) at the element x.

P44

Challenge: the Cantor–Bernstein theorem

Let f : A → B and g : B → A be injections. Prove that A ∼ B (Theorem 16, Lecture 1). Then use it to give an indirect proof that [a, b] ∼ (a, b) (Exercise 2.18).

Hint

Points of A outside g(B) must be sent by f. So must everything reached from them by g ∘ f. Send all other points back with g⁻¹.

Model proof

Let C₀ = A − g(B), Cₙ₊₁ = g(f(Cₙ)), and C = C₀ ∪ C₁ ∪ C₂ ∪ ⋯. Define h : A → B by h(x) = f(x) for x ∈ C and h(x) = g⁻¹(x) for x ∉ C. The second case makes sense: x ∉ C₀ means x ∈ g(B), and g⁻¹(x) is unique because g is injective.

Injective. On C, h = f is injective; off C, h = g⁻¹ is injective. Suppose f(x) = g⁻¹(x′) with x ∈ Cₙ and x′ ∉ C. Then x′ = g(f(x)) ∈ Cₙ₊₁ ⊆ C, a contradiction.

Surjective. Let y ∈ B. If g(y) ∉ C, then h(g(y)) = g⁻¹(g(y)) = y. If g(y) ∈ C, then g(y) ∉ C₀ (it lies in g(B)), so g(y) ∈ Cₙ₊₁ = g(f(Cₙ)) for some n. That is, g(y) = g(f(x)) with x ∈ Cₙ, and since g is injective, y = f(x) = h(x). So h is a bijection. ∎

Application. The inclusion (a, b) → [a, b] is injective. So is x ↦ m + (x − m)/2 from [a, b] to (a, b), where m = (a + b)/2: it shrinks [a, b] to the middle half, [(3a + b)/4, (a + 3b)/4] ⊂ (a, b). By Cantor–Bernstein, [a, b] ∼ (a, b), without building the bijection by hand as in P42.
