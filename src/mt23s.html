Task 1

Minimal AND–OR circuit · 4 pt

Design a three-input minimal AND–OR circuit L with truth table T[x, y, z; L] = [00001111, 00110011, 01010101; 01011111].

Solution

Step 1: positions 2, 4, 5, 6, 7, 8 give L = x′y′z + x′yz + xy′z′ + xy′z + xyz′ + xyz.

Steps 2–3: the whole x row and the four z squares are two 4-square blocks, so L = x + z. The circuit is a single OR gate with inputs x and z; no AND gates are needed.

Task 2

Truth table of an expression · 4 pt

Find T(E) for E = (x′y′ + z)′yz′ + (x′z + y)′(y′z + x) + x′z + xy′z′. Step 1: an SoP form (2 pt). Step 2: the CSoP form (1 pt). Step 3: T(E) (1 pt).

Hint

(x′y′ + z)′ = (x + y)z′ and (x′z + y)′ = (x + z′)y′. Finish with absorption.

Solution

(x + y)z′ · yz′ = xyz′ + yz′ = yz′

(xy′ + y′z′)(y′z + x) = xy′z + xy′ + y′z′y′z + xy′z′ = xy′

So E = yz′ + xy′ + x′z + xy′z′ = yz′ + xy′ + x′z.

CSoP: xyz′ + x′yz′ + xy′z + xy′z′ + x′yz + x′y′z: every minterm except x′y′z′ and xyz. So T(E) = 01111110.

Task 3

MSoP from a truth table · 3 pt

Find E(x, y, z) in MSoP form with T(E) = 11011100.

Solution

Positions 1, 2, 4, 5, 6: CSoP(E) = x′y′z′ + x′y′z + x′yz + xy′z′ + xy′z.

The four y′ squares form a block, and x′yz pairs with x′y′z: E = y′ + x′z.

Use Prim's algorithm to find a minimum spanning tree in the graph. Press the edges in the order Prim's algorithm adds them.

Task 5

Two 4-variable maps · 4 pt

Find an MSoP for each map. The checked squares, as they appear on the sheet:

(A) xyzt, xyzt′, xyz′t, xy′z′t′, xy′z′t, x′y′zt, x′y′zt′, the whole row x′y

(B) xyzt, xyz′t, xy′zt′, xy′z′t′, xy′z′t, the whole row x′y′, x′yzt, x′yzt′

Hint

(A) needs five products, four of them 2×2 blocks. (B) needs four; two of the blocks wrap around the edges of the map.

Answer

(A) One minimal sum: E = x′y + x′z + yz + yt + xy′z′ (5 products, 11 literals).

(B) One minimal sum: E = x′z + y′z′ + y′t′ + xyt (4 products, 9 literals).

The sheet counts 12 literals for (A); the sum it gives has 11.

Task 6

Quantifiers · 5 pt

6.1 The negation of ∀x ∃y ∀z P(x, y, z) is

  • ∃x ∃y ∃z ¬P(x, y, z)
  • ∀x ∃y ∀z ¬P(x, y, z)
  • ∃x ∀y ∃z ¬P(x, y, z)
  • ∃x ∀y ∀z ¬P(x, y, z)

¬∀x ∃y ∀z P = ∃x ¬∃y ∀z P = ∃x ∀y ¬∀z P = ∃x ∀y ∃z ¬P.

6.2 Over the integers, what are the truth values?

  1. ∃!x(x > 1)2, 3, 4, … all work: not unique.
  2. ∃!x(x² = 1)Two solutions: x = 1 and x = −1.
  3. ∃!x(x + 3 = 2x)Only x = 3.
  4. ∃!x(x = x + 1)It would need 0 = 1: no solution.
