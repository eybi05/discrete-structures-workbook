Regular induction · Lecture 6, Part 1

Task 1

Bernoulli's inequality

Use MI to prove that if h > −1, then 1 + nh ≤ (1 + h)ⁿ for all nonnegative integers n.

Hint

The basis is n = 0. In the step, multiply both sides of the hypothesis by 1 + h (why is that allowed?), expand, and drop a term that is never negative.

Model proof

Fix a real number h > −1. Let P(n) be the statement “1 + nh ≤ (1 + h)ⁿ”. We prove P(n) for all integers n ≥ 0.

Basis step. P(0) says 1 + 0·h ≤ (1 + h)⁰, that is, 1 ≤ 1, which is true.

Inductive step. Assume that P(k) is true for an arbitrary fixed integer k ≥ 0, that is, 1 + kh ≤ (1 + h)ᵏ (the inductive hypothesis). We must show P(k + 1): 1 + (k + 1)h ≤ (1 + h)ᵏ⁺¹.

Because h > −1, the number 1 + h is positive, so multiplying both sides of the inductive hypothesis by it keeps the direction of the inequality:

(1 + h)ᵏ⁺¹ = (1 + h)ᵏ(1 + h) ≥ (1 + kh)(1 + h) = 1 + h + kh + kh² = 1 + (k + 1)h + kh² ≥ 1 + (k + 1)h.

The last inequality holds because k ≥ 0 and h² ≥ 0, so kh² ≥ 0. Hence P(k + 1) is true. This completes the inductive step.

By mathematical induction, 1 + nh ≤ (1 + h)ⁿ for every nonnegative integer n. ∎

This is Exercise 2.13 of Lecture 6; P8.6(b) has the short version. The condition h > −1 is used exactly once, to multiply by 1 + h, and without it the claim can fail: for h = −3 and n = 5 the left side is −14 and the right side is (−2)⁵ = −32.

Self-check for your proof
  • Is your basis n = 0? The task says nonnegative integers, so starting at n = 1 leaves out P(0).
  • Did you say why multiplying by 1 + h keeps the inequality? (It is positive because h > −1.)
  • Did you justify dropping kh²?
  • The induction is on n; h stays fixed throughout.
Task 2

3ⁿ < n! for n > 6

Prove that 3ⁿ < n! if n is an integer greater than 6. Use MI.

Hint

The basis is n = 7. Then copy Example 4 of Lecture 6, which proves 2ⁿ < n!: write 3ᵏ⁺¹ = 3·3ᵏ and use 3 < k + 1.

Model proof

Let P(n) be the statement “3ⁿ < n!”. We prove P(n) for all integers n ≥ 7.

Basis step. P(7) is true, because 3⁷ = 2187 < 5040 = 7!.

Inductive step. Assume that P(k) is true for an arbitrary fixed integer k ≥ 7, that is, 3ᵏ < k!. We must show P(k + 1): 3ᵏ⁺¹ < (k + 1)!. We have

3ᵏ⁺¹ = 3·3ᵏ < 3·k! < (k + 1)·k! = (k + 1)!.

The first inequality is the inductive hypothesis multiplied by 3. The second holds because 3 < k + 1 (indeed k + 1 ≥ 8) and k! > 0. So P(k + 1) is true. This completes the inductive step.

By mathematical induction, 3ⁿ < n! for every integer n ≥ 7, that is, for every integer n > 6. ∎

This is Exercise 2.18 of Lecture 6. The basis cannot start lower: 3⁶ = 729 > 720 = 6! (see P8.2(b)).

Self-check for your proof
  • Does your basis use n = 7, with both sides computed?
  • Did you mark the place where the hypothesis 3ᵏ < k! is used?
  • Did you say why 3 < k + 1?
  • Is your conclusion stated for n ≥ 7, not for all positive integers?
Task 3

The sum 1·1! + 2·2! + ⋯ + n·n!

Prove that 1·1! + 2·2! + ⋯ + n·n! = (n + 1)! − 1 whenever n is a positive integer. Use MI.

Hint

Add the next term, (k + 1)·(k + 1)!, to both sides of the hypothesis and factor out (k + 1)!. Do not expand the factorials.

Model proof

Let P(n) be the statement “1·1! + 2·2! + ⋯ + n·n! = (n + 1)! − 1”.

Basis step. P(1) says 1·1! = 2! − 1. Both sides equal 1, so P(1) is true.

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: 1·1! + ⋯ + k·k! = (k + 1)! − 1. We must show P(k + 1): 1·1! + ⋯ + k·k! + (k + 1)·(k + 1)! = (k + 2)! − 1. Replacing the first k terms by the inductive hypothesis,

1·1! + ⋯ + k·k! + (k + 1)·(k + 1)! = (k + 1)! − 1 + (k + 1)·(k + 1)! = (k + 1)!·(1 + k + 1) − 1 = (k + 2)·(k + 1)! − 1 = (k + 2)! − 1.

This is P(k + 1), which completes the inductive step.

By mathematical induction, the identity holds for every positive integer n. ∎

This is Exercise 2.12 of Lecture 6; P8.6(a) has the short version. A check without induction: k·k! = (k + 1)! − k!, so the sum telescopes to (n + 1)! − 1!.

Self-check for your proof
  • Is the term you added (k + 1)·(k + 1)!, the term with n = k + 1?
  • Is your last expression exactly (k + 2)! − 1, the right side with n = k + 1?
  • Did you use (k + 2)·(k + 1)! = (k + 2)!, the definition of the factorial?
Task 4

Three-element subsets

Prove that a set with n elements has n(n − 1)(n − 2)/6 subsets containing exactly three elements whenever n is an integer greater than or equal to 3. Use MI.

Hint

Copy Exercise 1.3 of Lecture 6, which does this for two-element subsets. Take a set S with k + 1 elements, fix one element a, and count separately the three-element subsets that do not contain a and those that do.

Model proof

Let P(n) be the statement “every set with n elements has exactly n(n − 1)(n − 2)/6 three-element subsets”. We prove P(n) for all integers n ≥ 3.

Basis step. A set with 3 elements has exactly one three-element subset, namely itself, and 3·2·1/6 = 1. So P(3) is true.

Inductive step. Assume P(k) for an arbitrary fixed integer k ≥ 3: every set with k elements has k(k − 1)(k − 2)/6 three-element subsets. We must show that every set S with k + 1 elements has (k + 1)k(k − 1)/6 of them.

Choose an element a ∈ S and let T = S ∖ {a}, so |T| = k. Each three-element subset of S either does not contain a or contains it, and not both:

  • The subsets that do not contain a are exactly the three-element subsets of T. By the inductive hypothesis there are k(k − 1)(k − 2)/6 of them.
  • A subset that contains a is {a} ∪ X for exactly one two-element subset X of T. A k-element set has k(k − 1)/2 two-element subsets (Exercise 1.3 of Lecture 6), so there are k(k − 1)/2 of these.

Adding the two counts,

k(k − 1)(k − 2)/6 + k(k − 1)/2 = k(k − 1)[(k − 2) + 3]/6 = (k + 1)k(k − 1)/6,

which is n(n − 1)(n − 2)/6 with n = k + 1. So P(k + 1) is true. This completes the inductive step.

By mathematical induction, P(n) is true for every integer n ≥ 3. ∎

This is Exercise 2.22 of Lecture 6. P8.7 uses the formula: a 7-element set has 7·6·5/6 = 35 three-element subsets.

Self-check for your proof
  • Does your basis start at n = 3?
  • Did you explain why the two groups of subsets do not overlap and together give every three-element subset of S?
  • Did you justify the count k(k − 1)/2 for the subsets that contain a, by Exercise 1.3 or by choosing 2 of the k elements of T?
  • Does the algebra end in (k + 1)k(k − 1)/6?
Task 5

The derivative of xⁿ

Use MI to prove that the derivative of f(x) = xⁿ equals nxⁿ⁻¹ whenever n is a positive integer. (The sheet's hint: for the inductive step, use the product rule for derivatives.)

Hint

Write xᵏ⁺¹ = x·xᵏ. The product rule says (gh)′ = g′h + gh′; use the inductive hypothesis for the derivative of xᵏ.

Model proof

Write (g(x))′ for the derivative of g with respect to x. Let P(n) be the statement “(xⁿ)′ = nxⁿ⁻¹”.

Basis step. P(1) says (x)′ = 1·x⁰. The derivative of x is 1, and 1·x⁰ = 1, so P(1) is true.

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: (xᵏ)′ = kxᵏ⁻¹. We must show P(k + 1): (xᵏ⁺¹)′ = (k + 1)xᵏ. Since xᵏ⁺¹ = x·xᵏ, the product rule gives

(xᵏ⁺¹)′ = (x·xᵏ)′ = (x)′·xᵏ + x·(xᵏ)′ = 1·xᵏ + x·kxᵏ⁻¹ = xᵏ + kxᵏ = (k + 1)xᵏ.

The inductive hypothesis replaced (xᵏ)′ by kxᵏ⁻¹, and the basis step replaced (x)′ by 1. So P(k + 1) is true. This completes the inductive step.

By mathematical induction, (xⁿ)′ = nxⁿ⁻¹ for every positive integer n. ∎

This is Exercise 2.23 of Lecture 6.

Self-check for your proof
  • In the step, did you avoid the power rule itself? That is what you are proving.
  • Did you write xᵏ⁺¹ as a product and name the product rule?
  • Did you point to where the hypothesis (xᵏ)′ = kxᵏ⁻¹ is used?
Task 6

Too many points to be one-to-one

Suppose that m and n are positive integers with m > n and f: {1, 2, …, m} → {1, 2, …, n}. Use MI on the variable n to show that f is not one-to-one.

Hint

Let P(n) say “for every m > n, no function {1, …, m} → {1, …, n} is one-to-one”: the step needs the hypothesis for a different m. In the step, suppose f is one-to-one and look at the points that f sends to k + 1. There is none or exactly one; remove it and shift the later points down by one.

Model proof

For a positive integer n, let P(n) be the statement “for every integer m > n, no function f: {1, …, m} → {1, …, n} is one-to-one”. We prove P(n) for all n ≥ 1 by induction on n.

Basis step. Let m > 1 and f: {1, …, m} → {1}. Then m ≥ 2, and f(1) = f(2) = 1 although 1 ≠ 2. So f is not one-to-one, and P(1) is true.

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: for every m > k, no function {1, …, m} → {1, …, k} is one-to-one. We must show P(k + 1). So let m > k + 1 and f: {1, …, m} → {1, …, k + 1}, and suppose, to reach a contradiction, that f is one-to-one.

Case 1: no point is sent to k + 1. Then all values of f lie in {1, …, k}, so the same rule is a one-to-one function {1, …, m} → {1, …, k} with m > k + 1 > k. This contradicts the inductive hypothesis.

Case 2: f(j) = k + 1 for some j. Since f is one-to-one, j is the only such point. Remove j and close the gap: define g: {1, …, m − 1} → {1, …, k} by g(i) = f(i) for i < j and g(i) = f(i + 1) for i ≥ j. Then:

  • g takes the values of f at every point except j. None of them is k + 1, so g really maps into {1, …, k}.
  • g is one-to-one. The rule that sends i to i (if i < j) or to i + 1 (if i ≥ j) is increasing, so different i give different points of {1, …, m}, and f takes different values at different points.
  • m − 1 > k, because m > k + 1.

So g is a one-to-one function {1, …, m − 1} → {1, …, k} with m − 1 > k, which contradicts the inductive hypothesis (used with m − 1 in place of m).

Both cases lead to a contradiction, so f is not one-to-one, and P(k + 1) is true. This completes the inductive step.

By mathematical induction, P(n) is true for every positive integer n: if m > n, no function {1, …, m} → {1, …, n} is one-to-one. ∎

This is Exercise 2.14 of Lecture 6, the pigeonhole principle: if m pigeons go into n < m holes, some hole gets two pigeons.

Self-check for your proof
  • Does your P(n) say “for every m > n”? The step uses the hypothesis for m − 1, not for the same m.
  • In the basis, did you name two different points with the same value (this needs m ≥ 2)?
  • Did you handle the case where no point is sent to k + 1?
  • After removing j, did you check that the new function maps into {1, …, k}, is one-to-one, and has more points than values?
Task 7

aⁿ − bⁿ ≤ naⁿ⁻¹(a − b)

Suppose that a and b are real numbers with 0 < b < a. Prove that if n is a positive integer, then aⁿ − bⁿ ≤ naⁿ⁻¹(a − b).

Hint

Split the difference: aᵏ⁺¹ − bᵏ⁺¹ = a(aᵏ − bᵏ) + bᵏ(a − b). Use the hypothesis on the first term and bᵏ < aᵏ on the second.

Model proof

Fix real numbers a, b with 0 < b < a, and let P(n) be the statement “aⁿ − bⁿ ≤ naⁿ⁻¹(a − b)”. We use mathematical induction on n.

Basis step. P(1) says a − b ≤ 1·a⁰·(a − b) = a − b, which is true (with equality).

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: aᵏ − bᵏ ≤ kaᵏ⁻¹(a − b). We must show P(k + 1): aᵏ⁺¹ − bᵏ⁺¹ ≤ (k + 1)aᵏ(a − b). Adding and subtracting abᵏ,

aᵏ⁺¹ − bᵏ⁺¹ = aᵏ⁺¹ − abᵏ + abᵏ − bᵏ⁺¹ = a(aᵏ − bᵏ) + bᵏ(a − b).

We bound the two terms separately.

  • Multiplying the inductive hypothesis by a > 0: a(aᵏ − bᵏ) ≤ a·kaᵏ⁻¹(a − b) = kaᵏ(a − b).
  • Since 0 < b < a, we have bᵏ < aᵏ (multiply k copies of the inequality b < a between positive numbers), and a − b > 0. So bᵏ(a − b) < aᵏ(a − b).

Adding the two inequalities,

aᵏ⁺¹ − bᵏ⁺¹ ≤ kaᵏ(a − b) + aᵏ(a − b) = (k + 1)aᵏ(a − b).

So P(k + 1) is true. This completes the inductive step.

By mathematical induction, aⁿ − bⁿ ≤ naⁿ⁻¹(a − b) for every positive integer n. ∎

This is Exercise 2.20 of Lecture 6. A direct proof also works: aⁿ − bⁿ = (a − b)(aⁿ⁻¹ + aⁿ⁻²b + ⋯ + bⁿ⁻¹), and each of the n terms in the second bracket is at most aⁿ⁻¹.

Self-check for your proof
  • Did you check n = 1? Equality is fine, because the claim says ≤.
  • Did you show where the splitting identity comes from (add and subtract abᵏ)?
  • Did you use a > 0 to multiply the hypothesis, and bᵏ < aᵏ, a − b > 0 for the second term?
  • Is your final right side (k + 1)aᵏ(a − b), the formula with n = k + 1?
Task 8

When the step fails, prove more

Suppose that we want to prove that, for all positive integers n,

(1/2)·(3/4)⋯((2n − 1)/(2n)) < 1/√(3n).

  1. Show that if we try to prove this inequality using mathematical induction, the basis step works, but the inductive step fails.
  2. Show that mathematical induction can be used to prove the stronger inequality (1/2)·(3/4)⋯((2n − 1)/(2n)) < 1/√(3n + 1) for all n > 1, which, together with a verification for the case where n = 1, establishes the weaker inequality we originally tried to prove.
Hint

Write aₙ for the product, so that aₖ₊₁ = aₖ·(2k + 1)/(2k + 2). All numbers are positive, so you can compare squares and the square roots disappear. In (a), show that the bound you get from the hypothesis is always too big; in (b), the same computation leaves room to spare.

Model proof

Write aₙ = (1/2)·(3/4)⋯((2n − 1)/(2n)) for the product of the first n fractions. Then a₁ = 1/2, and since the (k + 1)st fraction is (2(k + 1) − 1)/(2(k + 1)) = (2k + 1)/(2k + 2),

aₖ₊₁ = aₖ·(2k + 1)/(2k + 2).

All numbers here are positive, and for positive x, y we have x < y ⟺ x² < y². That is how the square roots are removed below.

(a) Let P(n) be “aₙ < 1/√(3n)”.

The basis step works. P(1) says 1/2 < 1/√3; squaring gives 1/4 < 1/3, which is true.

The inductive step fails. Assume aₖ < 1/√(3k). The only link between aₖ and aₖ₊₁ is aₖ₊₁ = aₖ·(2k + 1)/(2k + 2), and it gives

aₖ₊₁ < (2k + 1)/((2k + 2)√(3k)).

To conclude P(k + 1) we would need this bound to be at most 1/√(3k + 3). Squaring and clearing the positive denominators, that means

(2k + 1)²(3k + 3) ≤ 3k(2k + 2)²
⟺ 3(k + 1)(2k + 1)² ≤ 12k(k + 1)²
⟺ (2k + 1)² ≤ 4k(k + 1)
⟺ 4k² + 4k + 1 ≤ 4k² + 4k,

that is, 1 ≤ 0, which is false for every k. So the bound from the hypothesis is always larger than 1/√(3(k + 1)). The hypothesis allows aₖ to be any number below 1/√(3k), even one very close to it, and (2k + 1)/(2k + 2) times such a number is more than 1/√(3k + 3). So P(k) alone does not give P(k + 1): the basis step works, but the inductive step cannot be completed. (The inequality is true; it is just too weak to carry itself from k to k + 1.)

(b) Let Q(n) be “aₙ < 1/√(3n + 1)”. We prove Q(n) for all integers n ≥ 2.

Basis step. a₂ = (1/2)·(3/4) = 3/8, and 3/8 < 1/√7 because (3/8)² = 9/64 < 1/7 (that is, 63 < 64). So Q(2) is true.

Inductive step. Assume Q(k) for an arbitrary fixed integer k ≥ 2: aₖ < 1/√(3k + 1). We must show Q(k + 1): aₖ₊₁ < 1/√(3k + 4). By the inductive hypothesis,

aₖ₊₁ = aₖ·(2k + 1)/(2k + 2) < (2k + 1)/((2k + 2)√(3k + 1)),

so it is enough to show (2k + 1)/((2k + 2)√(3k + 1)) ≤ 1/√(3k + 4). Squaring and clearing denominators, this says (2k + 1)²(3k + 4) ≤ (2k + 2)²(3k + 1). Expanding both sides:

(2k + 1)²(3k + 4) = 12k³ + 28k² + 19k + 4,
(2k + 2)²(3k + 1) = 12k³ + 28k² + 20k + 4.

The right side is larger by k > 0, so the inequality holds, and aₖ₊₁ < 1/√(3(k + 1) + 1). Thus Q(k + 1) is true. This completes the inductive step, and by mathematical induction Q(n) holds for every integer n ≥ 2.

Back to the original inequality. For n ≥ 2, aₙ < 1/√(3n + 1) < 1/√(3n), because 3n + 1 > 3n. For n = 1, a₁ = 1/2 < 1/√3 was checked in (a). Hence aₙ < 1/√(3n) for every positive integer n. ∎

This is the first Exercise 2.24 of Lecture 6 (the number 2.24 is used twice; see the errata). The stronger inequality is false at n = 1, where it would say 1/2 < 1/√4 = 1/2; that is why it starts at n = 2. Proving more also gives you more to assume, and here that extra strength is exactly the k of room in the last comparison.

Self-check for your proof
  • (a) Did you check the basis with numbers (1/4 < 1/3)?
  • (a) Did you show that the step fails for every k, not only for one value, and say why that means the induction cannot go through?
  • (b) Is your basis n = 2? At n = 1 the stronger inequality is false.
  • (b) Did you square both sides correctly and compare the expanded polynomials?
  • Did you go back to the original inequality at the end, including n = 1?

Task 9

Stamps of 4 and 7 cents

Let P(n) be the statement that a postage of n cents can be formed using just 4-cent stamps and 7-cent stamps. Use SI to prove that P(n) is true for n ≥ 18.

Hint

Add one 4-cent stamp to k − 3 cents. The step reaches back 4 places, so you need four basis cases: 18, 19, 20 and 21. P8.8 walks through the parts one at a time.

Model proof

We prove P(n) for all integers n ≥ 18 by strong induction.

Basis step. P(18), P(19), P(20) and P(21) are true:

  • 18 = 4 + 7 + 7 (one 4-cent and two 7-cent stamps)
  • 19 = 4 + 4 + 4 + 7 (three 4-cent stamps and one 7-cent stamp)
  • 20 = 4 + 4 + 4 + 4 + 4 (five 4-cent stamps)
  • 21 = 7 + 7 + 7 (three 7-cent stamps)

Inductive step. Let k ≥ 21 be an arbitrary fixed integer. The inductive hypothesis is that P(j) is true for every integer j with 18 ≤ j ≤ k: each of these amounts can be formed with 4-cent and 7-cent stamps. We must show P(k + 1): a postage of k + 1 cents can be formed.

Because k ≥ 21, we have 18 ≤ k − 3 ≤ k, so P(k − 3) is part of the inductive hypothesis: k − 3 cents can be formed. Adding one 4-cent stamp gives (k − 3) + 4 = k + 1 cents. So P(k + 1) is true. This completes the inductive step.

We have completed the basis step and the inductive step, so by strong induction P(n) is true for every integer n ≥ 18. ∎

This is the second Exercise 2.24 of Lecture 6. Four basis cases are needed because the step for k + 1 needs k − 3 ≥ 18, so it only proves P(22) onwards; 19, 20 and 21 cannot be reached from 18 by adding 4-cent stamps. And 18 is the right start: 17 cents cannot be formed (take away zero, one or two 7-cent stamps and you are left with 17, 10 or 3, none a multiple of 4).

Self-check for your proof
  • Did you give an explicit stamp combination for each of 18, 19, 20 and 21?
  • Is your hypothesis the strong one, P(j) for all j with 18 ≤ j ≤ k, and is k ≥ 21?
  • Did you say why P(k − 3) is covered by the hypothesis (k − 3 ≥ 18 because k ≥ 21)?
  • Does your conclusion say “by strong induction, for all n ≥ 18”?
Task 10

Stamps of 5 and 8 cents

Prove using SI that every amount of postage of 28 cents or more can be formed using just 5-cent and 8-cent stamps.

Before the proof: what is the largest amount that can not be formed? It explains why the claim starts at 28.

Hint

Add one 5-cent stamp to k − 4 cents. That reaches back 5 places, so you need five basis cases, 28 to 32. Each of them is a few 5s and a few 8s.

Model proof

Let P(n) be the statement “a postage of n cents can be formed using just 5-cent and 8-cent stamps”. We prove P(n) for all integers n ≥ 28 by strong induction.

Basis step. P(28), …, P(32) are true:

  • 28 = 5 + 5 + 5 + 5 + 8 (four 5-cent stamps and one 8-cent stamp)
  • 29 = 5 + 8 + 8 + 8 (one 5-cent and three 8-cent stamps)
  • 30 = 5 + 5 + 5 + 5 + 5 + 5 (six 5-cent stamps)
  • 31 = 5 + 5 + 5 + 8 + 8 (three 5-cent and two 8-cent stamps)
  • 32 = 8 + 8 + 8 + 8 (four 8-cent stamps)

Inductive step. Let k ≥ 32 be an arbitrary fixed integer, and assume the inductive hypothesis: P(j) is true for every integer j with 28 ≤ j ≤ k. We must show P(k + 1).

Because k ≥ 32, we have 28 ≤ k − 4 ≤ k, so by the inductive hypothesis k − 4 cents can be formed. Adding one 5-cent stamp gives (k − 4) + 5 = k + 1 cents, so P(k + 1) is true. This completes the inductive step.

By strong induction, every postage of n ≥ 28 cents can be formed using just 5-cent and 8-cent stamps. ∎

The answer to the box: 27 cents cannot be formed (take away zero to three 8-cent stamps and you are left with 27, 19, 11 or 3, none a multiple of 5), so the claim cannot start lower. For two stamp values a, b with no common divisor greater than 1, the largest impossible amount is ab − a − b: here 40 − 5 − 8 = 27, and in Task 9 28 − 4 − 7 = 17. You do not need this fact for the proof.

Self-check for your proof
  • Five basis cases, 28 to 32, each with an explicit combination?
  • Is your hypothesis the strong one, for all j from 28 to k, with k ≥ 32?
  • Did you check that k − 4 ≥ 28, so that the hypothesis covers it?
  • If your step adds an 8-cent stamp instead, it reaches back 8 places and needs eight basis cases, 28 to 35. That is also correct.

Recursive sets and structural induction · Lecture 7

Task 11

Pairs with a ≤ 2b

Let S be the subset of the set of ordered pairs of integers defined recursively by

Basis step: (0, 0) ∈ S.
Recursive step: if (a, b) ∈ S, then (a, b + 1) ∈ S, (a + 1, b + 1) ∈ S and (a + 2, b + 1) ∈ S.

  1. List the elements of S produced by the first three applications of the recursive definition.
  2. Use strong induction on the number of applications of the recursive step of the definition to show that a ≤ 2b whenever (a, b) ∈ S.
  3. Use structural induction to show that a ≤ 2b whenever (a, b) ∈ S.

For (a), type the new pairs of each application, for example (0, 1), (1, 1), in any order.

Hint

(a) Apply all three rules to every pair you have so far. Each rule raises b by exactly 1, so the pairs from the nth application all have b = n. (b) Let P(n) be about the elements obtained by n applications; the last application starts from an element obtained by fewer. (c) Check the basis element and each of the three rules.

Model proof

(a) The basis step gives (0, 0). Every rule raises the second coordinate by exactly 1 and the first by 0, 1 or 2. So the pairs produced by the nth application are the pairs (a, n) where a is a sum of n numbers from {0, 1, 2}, that is, any whole number from 0 to 2n:

  • 1st application (from (0, 0)): (0, 1), (1, 1), (2, 1)
  • 2nd application: (0, 2), (1, 2), (2, 2), (3, 2), (4, 2)
  • 3rd application: (0, 3), (1, 3), (2, 3), (3, 3), (4, 3), (5, 3), (6, 3)

That is 3 + 5 + 7 = 15 new elements, besides (0, 0).

(b) For n ≥ 0, let P(n) be the statement “a ≤ 2b for every (a, b) ∈ S obtained by n applications of the recursive step”. We prove P(n) for all n ≥ 0 by strong induction.

Basis step. The only element obtained with no application of the recursive step is (0, 0), and 0 ≤ 2·0. So P(0) is true.

Inductive step. Let k ≥ 0 be an arbitrary fixed integer and assume P(0), P(1), …, P(k): every element obtained by at most k applications satisfies a ≤ 2b. Let (c, d) be an element obtained by k + 1 applications. The last application was made to an element (a, b) ∈ S obtained by k applications, so a ≤ 2b by the inductive hypothesis, and (c, d) is one of the three new pairs:

  • (a, b + 1): a ≤ 2b ≤ 2b + 2 = 2(b + 1);
  • (a + 1, b + 1): a + 1 ≤ 2b + 1 ≤ 2(b + 1);
  • (a + 2, b + 1): a + 2 ≤ 2b + 2 = 2(b + 1).

In every case c ≤ 2d, so P(k + 1) is true. This completes the inductive step.

By strong induction, P(n) is true for every n ≥ 0. Every element of S is obtained by some finite number of applications (the exclusion rule), so a ≤ 2b for every (a, b) ∈ S. ∎

(c) Basis step. The element put into S by the basis step, (0, 0), satisfies 0 ≤ 2·0.

Recursive step. Let (a, b) ∈ S and assume that a ≤ 2b. The recursive step builds (a, b + 1), (a + 1, b + 1) and (a + 2, b + 1) from it, and the three lines in (b) show that each of them satisfies the inequality: a ≤ 2(b + 1), a + 1 ≤ 2(b + 1) and a + 2 ≤ 2(b + 1).

By structural induction, a ≤ 2b for every (a, b) ∈ S. ∎

Parts (b) and (c) are the same argument. Structural induction is (b) without the counting of applications, and Theorem 3 of Lecture 7 shows that this is allowed. Here each rule starts from a single element, so only P(k) was really used in (b); write it as strong induction anyway, since the task asks for it. Strong induction is essential for rules that combine two elements, such as x + y in Example 8 of Lecture 7, where the two can come from different numbers of applications.

Self-check for your proof
  • (a) Did you list only the new pairs of each application, without repeats?
  • (b) Is your P(n) about the elements obtained by n applications, with the basis at n = 0?
  • (b) Did you say that the last application starts from an element covered by the hypothesis?
  • (b), (c) Did you check all three rules, not just one?
  • (c) A structural induction proof has no n in it: only the basis element and the rules.
Task 12

Pairs with 5 | a + b

Let S be the subset of the set of ordered pairs of integers defined recursively by

Basis step: (0, 0) ∈ S.
Recursive step: if (a, b) ∈ S, then (a + 2, b + 3) ∈ S and (a + 3, b + 2) ∈ S.

  1. List the elements of S produced by the first four applications of the recursive definition.
  2. Use strong induction on the number of applications of the recursive step of the definition to show that 5 | a + b when (a, b) ∈ S.
  3. Use structural induction to show that 5 | a + b when (a, b) ∈ S.

For (a), type the new pairs of each application, in any order.

Hint

Each rule adds 5 to a + b. In (a), the order in which the two rules are used does not matter, only how many times each is used.

Model proof

(a) Each rule adds 2 to one coordinate and 3 to the other. After n applications, with i uses of the first rule and n − i of the second (in any order), the pair is (2i + 3(n − i), 3i + 2(n − i)) = (3n − i, 2n + i) for i = 0, 1, …, n:

  • 1st application: (2, 3), (3, 2)
  • 2nd application: (4, 6), (5, 5), (6, 4)
  • 3rd application: (6, 9), (7, 8), (8, 7), (9, 6)
  • 4th application: (8, 12), (9, 11), (10, 10), (11, 9), (12, 8)

That is 2 + 3 + 4 + 5 = 14 new elements, besides (0, 0).

(b) For n ≥ 0, let P(n) be the statement “5 | a + b for every (a, b) ∈ S obtained by n applications of the recursive step”. We use strong induction.

Basis step. The only element obtained with no application is (0, 0), and 0 + 0 = 0 = 5·0. So P(0) is true.

Inductive step. Let k ≥ 0 be an arbitrary fixed integer and assume P(0), …, P(k). Let (c, d) be obtained by k + 1 applications. The last application was made to an element (a, b) obtained by k applications, so by the inductive hypothesis a + b = 5m for some integer m. Then (c, d) is (a + 2, b + 3) or (a + 3, b + 2), and in both cases

c + d = a + b + 5 = 5m + 5 = 5(m + 1).

So 5 | c + d, and P(k + 1) is true. This completes the inductive step. By strong induction, P(n) holds for every n ≥ 0, and since every element of S is obtained by finitely many applications, 5 | a + b for every (a, b) ∈ S. ∎

(c) Basis step. For the basis element (0, 0), a + b = 0 = 5·0.

Recursive step. Let (a, b) ∈ S and assume 5 | a + b, say a + b = 5m. The new elements are (a + 2, b + 3) and (a + 3, b + 2), and for both the sum of the coordinates is a + b + 5 = 5(m + 1), which is divisible by 5.

By structural induction, 5 | a + b for every (a, b) ∈ S. ∎

The pairs in (a) agree: the sums are 5, 10, 15 and 20. The converse is false: (5, 0) has 5 | a + b but is not in S, because both coordinates of every element other than (0, 0) are at least 2.

Self-check for your proof
  • (a) Did you get n + 1 new pairs at the nth application, each with a + b = 5n?
  • (b) Basis at n = 0, and does the step say which earlier element the last application starts from?
  • Did you write “divisible by 5” as an equation, a + b = 5m, so that you can compute with it?
  • (b), (c) Did you check both rules?

Task 13

A telescoping sum

Prove, using MI:

1/(1·5) + 1/(5·9) + ⋯ + 1/((4n − 3)(4n + 1)) = n/(4n + 1).

Hint

The (k + 1)st term is 1/((4k + 1)(4k + 5)), because 4(k + 1) − 3 = 4k + 1. Put both fractions over (4k + 1)(4k + 5) and factor the numerator.

Model proof

Let P(n) be the statement “1/(1·5) + 1/(5·9) + ⋯ + 1/((4n − 3)(4n + 1)) = n/(4n + 1)”.

Basis step. P(1) says 1/(1·5) = 1/(4·1 + 1); both sides equal 1/5.

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: the sum of the first k terms is k/(4k + 1). The (k + 1)st term is 1/((4(k + 1) − 3)(4(k + 1) + 1)) = 1/((4k + 1)(4k + 5)), and we must show that the sum of the first k + 1 terms is (k + 1)/(4k + 5). Replacing the first k terms by the inductive hypothesis,

k/(4k + 1) + 1/((4k + 1)(4k + 5)) = (k(4k + 5) + 1)/((4k + 1)(4k + 5)) = (4k² + 5k + 1)/((4k + 1)(4k + 5)) = (4k + 1)(k + 1)/((4k + 1)(4k + 5)) = (k + 1)/(4k + 5).

Since 4k + 5 = 4(k + 1) + 1, this is P(k + 1). This completes the inductive step.

By mathematical induction, the identity holds for every positive integer n. ∎

This is Exercise 2.7 of Lecture 6; Exercise 2.6 is the same with 2n ± 1. A check without induction: 1/((4j − 3)(4j + 1)) = (1/4)(1/(4j − 3) − 1/(4j + 1)), so the sum telescopes to (1/4)(1 − 1/(4n + 1)) = n/(4n + 1).

Self-check for your proof
  • Did you put k + 1 into both factors of the last term, to get (4k + 1)(4k + 5)?
  • Did you factor 4k² + 5k + 1 = (4k + 1)(k + 1) and cancel 4k + 1?
  • Did you write the result as (k + 1)/(4(k + 1) + 1), so that it is visibly P(k + 1)?
Task 14

5 divides 7ⁿ − 2ⁿ

Prove that 7ⁿ − 2ⁿ is divisible by 5 for all n ∈ ℕ. Use MI.

Hint

Add and subtract 7·2ᵏ: 7ᵏ⁺¹ − 2ᵏ⁺¹ = 7(7ᵏ − 2ᵏ) + 5·2ᵏ.

Model proof

In this course ℕ is the set of positive integers, so we prove the claim for all n ≥ 1. Let P(n) be the statement “5 | 7ⁿ − 2ⁿ”.

Basis step. 7¹ − 2¹ = 5 = 5·1, so P(1) is true.

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: 7ᵏ − 2ᵏ = 5m for some integer m. We must show 5 | 7ᵏ⁺¹ − 2ᵏ⁺¹. Adding and subtracting 7·2ᵏ,

7ᵏ⁺¹ − 2ᵏ⁺¹ = 7·7ᵏ − 7·2ᵏ + 7·2ᵏ − 2·2ᵏ = 7(7ᵏ − 2ᵏ) + 5·2ᵏ = 7·5m + 5·2ᵏ = 5(7m + 2ᵏ).

Since 7m + 2ᵏ is an integer, 7ᵏ⁺¹ − 2ᵏ⁺¹ is divisible by 5, and P(k + 1) is true. This completes the inductive step.

By mathematical induction, 5 | 7ⁿ − 2ⁿ for every n ∈ ℕ. ∎

This is Exercise 2.8 of Lecture 6 and P8.5(a). If your ℕ includes 0, add the case 7⁰ − 2⁰ = 0 = 5·0. A check without induction: the factorisation in the note to Task 7 gives 7ⁿ − 2ⁿ = (7 − 2)(7ⁿ⁻¹ + 7ⁿ⁻²·2 + ⋯ + 2ⁿ⁻¹).

Self-check for your proof
  • Basis at n = 1, and n = 0 too if your ℕ contains 0?
  • Did you write the hypothesis as an equation, 7ᵏ − 2ᵏ = 5m?
  • Did you end with 5 times an integer, and say that it is an integer?
Task 15

3 divides n³ − 4n + 6

Prove that n³ − 4n + 6 is divisible by 3 for all n ∈ ℕ. Use MI.

Hint

Expand (k + 1)³ − 4(k + 1) + 6 and look for k³ − 4k + 6 inside it. What is left over is a multiple of 3.

Model proof

Let P(n) be the statement “3 | n³ − 4n + 6”, for n ∈ ℕ, the positive integers.

Basis step. 1³ − 4·1 + 6 = 3 = 3·1, so P(1) is true.

Inductive step. Assume P(k) for an arbitrary fixed positive integer k: k³ − 4k + 6 = 3m for some integer m. We must show 3 | (k + 1)³ − 4(k + 1) + 6. Expanding,

(k + 1)³ − 4(k + 1) + 6 = k³ + 3k² + 3k + 1 − 4k − 4 + 6 = (k³ − 4k + 6) + 3k² + 3k − 3 = 3m + 3(k² + k − 1) = 3(m + k² + k − 1).

Since m + k² + k − 1 is an integer, P(k + 1) is true. This completes the inductive step.

By mathematical induction, 3 | n³ − 4n + 6 for every n ∈ ℕ. ∎

This is Exercise 2.9 of Lecture 6 and P8.5(b). For n = 0 the value is 6, also divisible by 3.

Self-check for your proof
  • Is your expansion right: (k + 1)³ = k³ + 3k² + 3k + 1?
  • Did you regroup into the hypothesis part plus 3(k² + k − 1), rather than only checking a few values of n?
  • Did you end with 3 times an integer?
